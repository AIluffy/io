# React Example

## Run

```bash
npm install
npm run dev
```

## What it demonstrates

- Todo demo (add / toggle / remove / filter)
- `@iostore/store`: tree nodes for object + array state
- `@iostore/react`: `useIO(source)` subscribes via `snapshot() + subscribe()`
