# Svelte Example

## Run

```bash
npm install
npm run dev
```

## What it demonstrates

- Todo demo (add / toggle / remove / filter)
- `io-store`: tree nodes for object + array state
- `io-svelte`: `toReadable(source)` bridges `snapshot() + subscribe()`
