# Vanilla (HTML + TS) Example

## Run

```bash
npm install
npm run dev
```

## What it demonstrates

- IO async state patterns in plain DOM
- List, detail, form, and long task templates
- Tailwind-based UI structure without a framework

## Async templates

- `src/templates/async/list.ts`
- `src/templates/async/detail.ts`
- `src/templates/async/form.ts`
- `src/templates/async/long-task.ts`
