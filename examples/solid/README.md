# Solid Example

## Run

```bash
npm install
npm run dev
```

## What it demonstrates

- Todo demo (add / toggle / remove / filter)
- `io-store`: tree nodes for object + array state
- `io-solid`: `useIO(source)` returns Solid accessors from `snapshot() + subscribe()`
