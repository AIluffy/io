# Vue Example

## Run

```bash
npm install
npm run dev
```

## What it demonstrates

- Todo demo (add / toggle / remove / filter)
- `@iostore/store`: tree nodes for object + array state
- `@iostore/vue`: `useIO(source)` bridges `snapshot() + subscribe()`
