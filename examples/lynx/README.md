# Lynx Example

## Run

```bash
npm install
nx run io-example-lynx:dev
```

## What it demonstrates

- Todo demo (add / toggle / remove / filter)
- `@iostore/store`: tree nodes for object + array state
- `@iostore/lynx`: `useIO(source)` in ReactLynx (`view/text/input` + `bind*` events)
