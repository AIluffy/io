npm 包 `@iostore/svelte` 提供与 Svelte Stores 兼容的 `toReadable` / `toWritable` 适配器。

## toReadable

```ts
import { io } from '@iostore/store';
import { toReadable } from '@iostore/svelte';

const store = io({ count: 0 });
const readable = toReadable(store.count);
```

## toWritable

```ts
import { toWritable } from '@iostore/svelte';

const writable = toWritable(store.count);
```

## 调度策略

```ts
const readable = toReadable(store.count, { schedule: 'sync' });
```

可选值：`sync` | `microtask` | `animationFrame`。

## Query / Resource

安装 Query 包：

```bash
npm i @iostore/query
```

`@iostore/svelte` 提供 `createQueryStore` 与 `toQueryStore`：

```ts
import { createQueryStore } from '@iostore/svelte';

const userStore = createQueryStore({
  key: ['user', id],
  queryFn: async () => fetch(`/api/users/${id}`).then((r) => r.json()),
});
```
