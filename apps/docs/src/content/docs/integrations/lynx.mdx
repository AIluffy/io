npm 包 `@iostore/lynx` 提供 `useIO` 与 `useIOSelector`，用于在 ReactLynx 中订阅 IO 数据源。

## 基础用法

```tsx
import { root } from '@lynx-js/react';
import { io } from '@iostore/store';
import { useIO } from '@iostore/lynx';

const count = io(0);

function Counter() {
  const value = useIO(count);
  return (
    <view>
      <text>{value}</text>
      <view bindtap={() => count.set((v) => v + 1)}>
        <text>+1</text>
      </view>
    </view>
  );
}

root.render(<Counter />);
```

## TypeScript 配置

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@lynx-js/react"
  }
}
```

## useIOSelector

```tsx
import { useIOSelector } from '@iostore/lynx';

const store = io({ count: 0, other: 0 });

function CountOnly() {
  const count = useIOSelector(store, (state) => state.count);
  return <text>{count}</text>;
}
```

如需自定义比较逻辑：

```tsx
const parity = useIOSelector(store, (state) => ({ p: state.count % 2 }), {
  isEqual: (prev, next) => prev.p === next.p,
});
```

## 调度策略

```tsx
const value = useIO(count, { schedule: 'microtask' });
```

可选值：`sync` | `microtask` | `animationFrame`。

## 注意事项

- 使用 Lynx 原生标签和事件：`view` / `text` / `input` 与 `bindtap` / `bindinput`。
- 应用入口使用 `root.render(...)`，而不是 Web 的 `createRoot`。
