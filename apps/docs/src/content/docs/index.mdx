## 上手示例

```ts
import { io, batch } from '@iostore/store';

const store = io({ count: 0, user: { name: 'Ada' } });

store.user.name.set('Grace');

batch(() => {
  store.count.set((v) => v + 1);
  store.count.set((v) => v + 1);
});
```

框架适配：[React](/integrations/react/) · [Solid](/integrations/solid/) · [Vue](/integrations/vue/) · [Svelte](/integrations/svelte/)

## 为什么是 IO

<CardGrid stagger>
  <Card title="深层直改" icon="seti:stylus">
    直接写任意层级字段，减少 reducer/样板代码。
  </Card>
  <Card title="细粒度订阅" icon="sourcehut">

  </Card>
  <Card title="可预测快照" icon="approve-check-circle">

  </Card>
  <Card title="可组合扩展" icon="puzzle">
    Persist、Schedule、DevTools 以行为扩展方式装配。
  </Card>
