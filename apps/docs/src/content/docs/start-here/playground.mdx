Playground 提供一个安全的交互环境，便于验证更新、快照与 patch。

适合用来：

- 快速理解“路径级订阅”的效果。
- 对比批处理前后的 patch 输出。
- 观察同一更新在不同调度策略下的通知节奏。

## 快速体验

1. 修改 `count` 与 `user.name`。
2. 切换批处理开关，对比 patch 输出。
3. 观察订阅叶子与订阅根节点的差异。

## 推荐试验

- 修改深层字段，观察 patch 路径。
- 比较 `snapshot()` 与 `get()` 的输出。
- 切换调度策略，观察通知频率。
