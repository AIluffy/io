The npm package `@iostore/vue` provides `useIO` (read-only) and `ioRef` (two-way binding) for Vue refs.

## useIO

```ts
import { io } from '@iostore/store';
import { useIO } from '@iostore/vue';

const store = io({ count: 0 });

const state = useIO(store.count);
```

`useIO` returns a `ShallowRef` for template usage.

## ioRef (Two-way Binding)

```ts
import { ioRef } from '@iostore/vue';

const countRef = ioRef(store.count);
```

## Scheduling

```ts
const state = useIO(store.count, { schedule: 'microtask' });
```

Available: `sync` | `microtask` | `animationFrame`.
