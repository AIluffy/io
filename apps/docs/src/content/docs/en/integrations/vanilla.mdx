IO is framework-agnostic. Use `snapshot()` + `subscribe()` directly.

## Basic Example

```ts
import { io } from 'io-store';

const store = io({ count: 0 });

const stop = store.count.subscribe((value) => {
  console.log('render', value);
});

store.count.set(1);
stop();
```

## Subscribe to Updates

```ts
const stopUpdate = store.subscribeUpdate((update) => {
  console.log(update.patches);
});
```

## Manual Scheduling

Use `batch()` or the `schedule()` behavior to coalesce notifications.

```ts
import { batch } from 'io-store';

batch(() => {
  store.count.set(1);
  store.count.set(2);
});
```
