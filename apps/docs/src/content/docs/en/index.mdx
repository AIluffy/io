## Quick Start

```ts
import { io, batch } from '@iostore/store';

const store = io({ count: 0, user: { name: 'Ada' } });

store.user.name.set('Grace');

batch(() => {
  store.count.set((v) => v + 1);
  store.count.set((v) => v + 1);
});
```

## Why IO

<CardGrid stagger>
  <Card title="Deep, direct" icon="seti:stylus">
    Update nested paths without reducers or boilerplate.
  </Card>
  <Card title="Fine-grained" icon="sourcehut">
    Subscriptions stay precise so work stays local.
  </Card>
  <Card title="Predictable" icon="approve-check-circle">
    Frozen snapshots and patch-based writes for replay/undo.
  </Card>
  <Card title="Composable" icon="puzzle">

  </Card>
