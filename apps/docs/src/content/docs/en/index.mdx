## Quick Start

```ts
import { io, batch } from 'io-store';

const store = io({ count: 0, user: { name: 'Ada' } });

store.user.name.set('Grace');

batch(() => {
  store.count.update((v) => v + 1);
  store.count.update((v) => v + 1);
});
```

## Architecture at a Glance

- **Unit + Tree**: leaves and trees share the same runtime.
- **Snapshot cache**: rebuild only dirty paths.
- **Update log**: patches make time travel natural.
- **Unified adapters**: `snapshot()` + `subscribe()` everywhere.
