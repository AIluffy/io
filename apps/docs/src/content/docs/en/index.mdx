## Quick Start

<Tabs default="core">
  <TabItem label="Core" id="core">
    ```ts
    import { io } from 'io-store';

    const count = io(0);

    count.get();
    count.update((v) => v + 1);
    ```

  </TabItem>
  <TabItem label="React">
    ```tsx
    import { io } from 'io-store';
    import { useIO } from 'io-react';

    const count = io(0);

    export function Counter() {
      const value = useIO(count);
      return (
        <button onClick={() => count.update((v) => v + 1)}>{value}</button>
      );
    }
    ```

  </TabItem>
  <TabItem label="Vue">
    ```ts
    import { io } from 'io-store';
    import { useIO, ioRef } from 'io-vue';

    const count = io(0);
    const countRef = ioRef(count);

    export function useCounter() {
      const state = useIO(count);
      const inc = () => count.update((v) => v + 1);
      const reset = () => countRef.value = 0;
      return { state, countRef, inc, reset };
    }
    ```

  </TabItem>
  <TabItem label="Svelte">
    ```ts
    import { io } from 'io-store';
    import { toWritable } from 'io-svelte';

    const count = io(0);
    export const countStore = toWritable(count);
    ```

  </TabItem>
</Tabs>

## Why IO

<CardGrid stagger>
  <Card title="Atomic" icon="sourcehut">
    State decomposed into independent atoms for precise subscriptions with zero
    extra renders.
  </Card>
  <Card title="Direct Paths" icon="seti:stylus">
    Read and write nested paths at any depth without changing your APIs.
  </Card>
  <Card title="Immutable Snapshots" icon="approve-check-circle">
    Frozen snapshots with replayable change logs for predictable state.
  </Card>
  <Card title="Behaviors" icon="puzzle">
    Compose persist, schedule, and DevTools capabilities.
  </Card>
  <Card title="Multi-Framework" icon="setting">
    React, Vue, and Svelte adapters share the same core contract.
  </Card>
</CardGrid>
