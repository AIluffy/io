## Patch and Update

IO records each write as a `patch` (`set` / `splice` / `sort`) and groups patches into an `update`. Updates can be merged, inverted (undo), or replayed.

```ts
import { io } from 'io-store';

const count = io(0);

const unsub = count.subscribeUpdate((update) => {
  console.log(update.patches);
});

count.set(1);
unsub();
```

:::tip
Subscribe at the tree root to capture changes across the whole store.
:::

:::note
`subscribeUpdate()` is about “what changed” (patches). If you also need the latest value, read it with `snapshot()`/`get()` (or use `subscribe()` for value-driven updates).
:::

## onMutation and onError

Use the debug helpers for cross-cutting observability.

```ts
import { onMutation, onError, io } from 'io-store';

const store = io({ count: 0 });

const stop = onMutation(store, (patch, path) => {
  console.log(path, patch.op, patch.next);
});

const stopError = onError(store, (error, path, op) => {
  console.error('failed', op, path, error);
});
```

## Update utilities

```ts
import { applyUpdate, mergeUpdates, undoUpdate, io } from 'io-store';

const store = io({ count: 0 });
const updates = [];
const unsub = store.subscribeUpdate((u) => updates.push(u));

store.count.set(1);
store.count.set(2);
unsub();

const replayStore = io({ count: 0 });
applyUpdate(replayStore, updates);

const merged = mergeUpdates(...updates);
const inverted = undoUpdate(merged);

applyUpdate(store, inverted);
```

## Undo / redo

Use `createHistory` for a ready-to-go undo/redo flow:

```ts
import { createHistory, io } from 'io-store';

const store = io({ count: 0 });
const history = createHistory(store);

store.count.set(1);
store.count.set(2);

history.undo();
history.redo();
```
