IO records every write as a structured `patch`, grouped into `update` objects. This is the basis for replay and audit trails.

## Patch Types

- `set`: assign a value at a path
- `splice`: array insert/delete
- `sort`: array reorder

## Subscribe to Updates

```ts
import { io } from 'io-store';

const store = io({ count: 0 });

const stop = store.subscribeUpdate((update) => {
  console.log(update.patches);
});

store.count.set(1);
stop();
```

:::note
`subscribeUpdate()` tells you what changed. Use `snapshot()` or `subscribe()` for latest values.
:::

## Replay and Undo

```ts
import { applyUpdate, mergeUpdates, undoUpdate, replay, io } from 'io-store';

const store = io({ count: 0 });
const updates: any[] = [];
const stop = store.subscribeUpdate((u) => updates.push(u));

store.count.set(1);
store.count.set(2);
stop();

const replayStore = io({ count: 0 });
replay(replayStore, updates);

const merged = mergeUpdates(...updates);
const inverted = undoUpdate(merged);
applyUpdate(store, inverted);
```

## Undo / Redo

```ts
import { createHistory, io } from 'io-store';

const store = io({ count: 0 });
const history = createHistory(store, { limit: 100 });

store.count.set(1);
store.count.set(2);

history.undo();
history.redo();
```

## Debug Hooks

```ts
import { io, onMutation, onError } from 'io-store';

const store = io({ count: 0 });

const stopMutation = onMutation(store, (patch, path) => {
  console.log(path, patch.op);
});

const stopError = onError(store, (error, path, op) => {
  console.error(op, path, error);
});
```
