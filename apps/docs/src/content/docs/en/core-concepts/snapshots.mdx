IO reads return **frozen snapshots** so accidental mutations don't leak back into state.

## snapshot vs get

- `snapshot()`: returns frozen data, safe for serialization and sharing.
- `get()`: reads the current value and participates in dependency tracking.

```ts
const store = io({ count: 0 });

const snap = store.snapshot();
const value = store.count.get();
```

## Why Freeze

- Prevents accidental mutation in UI layers.
- Enables safe caching and reuse.
- Makes diffing and replay reliable.

## Snapshot Cache

Tree nodes cache snapshots and only rebuild for dirty paths.

## Guidance

- Use `snapshot()` when handing data to UI or external systems.
- Use `get()` inside `derived()` and selectors.
