## Frozen by default

Any read that returns an object or array is frozen. This prevents accidental in-place mutation and makes comparisons safer.

```ts
import { io } from 'io-store';

const state = io({ items: ['a', 'b'] });
const snapshot = state.snapshot();

Object.isFrozen(snapshot); // true
```

## Snapshot API

Every Unit and Scope exposes `snapshot()`.

```ts
const count = io(0);

count.snapshot();
```

Snapshots are **referentially stable** within the same revision, which is helpful for memoization and UI rendering.

## `get()` vs `snapshot()`

- Use `get()` when you want the read to participate in dependency tracking (for example inside `derived()`).
- Use `snapshot()` when you just want the value without being tracked.
