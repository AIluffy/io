## Deep by default

`io()` walks plain objects and arrays and turns nested paths into nodes. In practice, that means you can update deep values without reducers or ceremony.

```ts
import { io } from 'io-store';

const state = io({ user: { profile: { name: 'Ada' } } });

state.user.profile.name.get();
state.user.profile.name.set('Grace');
```

## Shallow mode

If you only want the first level as Units, use `shallow: true`. This keeps the tree shallow (depth 1) and treats deeper values as plain data.

```ts
const state = io({ user: { name: 'Ada' } }, { shallow: true });

state.user.get(); // returns the plain object
state.user.set({ name: 'Grace' });
```

`commit` in shallow mode rejects unknown keys to keep the shape stable.

## Focus on one path

Use `relocate` to create a view for a specific path (useful when passing state around without exposing the whole tree).

```ts
import { relocate, io } from 'io-store';

const store = io({ settings: { theme: 'light' } });
const theme = relocate<string>(store, ['settings', 'theme']);

theme.get(); // 'light'
theme.set?.('dark'); // only works when the target is a Unit
```
