IO defaults to deep mode: objects and arrays expand into a subscribable tree.

## Deep Access

```ts
import { io } from 'io-store';

const store = io({
  user: { profile: { name: 'Ada' } },
  items: [{ id: 1, count: 0 }],
});

store.user.profile.name.set('Grace');
store.items[0].count.update((v) => v + 1);
```

Every path behaves like a Unit, so you can subscribe at leaf level.

You can think of this as “automatic atomization”: Trees organize structure, while path Units provide atom-level reads, writes, and subscriptions.

## Shallow Mode

If you only want the first level to be Units:

```ts
const shallow = io({ name: 'Ada', age: 36 }, { shallow: true });

shallow.name.set('Lin');
```

Shallow mode limits depth to 1 and keeps structure stable.

## Structural Constraints

- Deep mode only supports **plain objects** and **arrays**.
- Passing class instances throws `TypeError`.

Wrap complex values in a plain object if needed.
