## Deep by default

`io()` walks objects and arrays and converts nested paths into Units. You can update deep values without switching APIs.

```ts
import { io } from 'io-store';

const state = io({ user: { profile: { name: 'Ada' } } });

state.user.profile.name();
state.user.profile.name('Grace');
```

## Shallow mode

If you only want the first level as Units, use `shallow: true` (shallow uses the
same tree engine with depth limited to 1).

```ts
const state = io({ user: { name: 'Ada' } }, { shallow: true });

state.user(); // returns the plain object
state.user({ name: 'Grace' });
```

`commit` in shallow mode rejects unknown keys to keep the shape stable.

## Focus for explicit paths

Use `relocate` to build a view for a specific path.

```ts
import { relocate, io } from 'io-store';

const store = io({ settings: { theme: 'light' } });
const theme = relocate<string>(store, ['settings', 'theme']);

theme('dark');
```
