This page explains the two foundational shapes in IO: Units (values) and Scopes (objects).

## Unit

A Unit is the smallest writable cell with clear read/write APIs.

```ts
import { io } from '@iostore/store';

const count = io(0);

count.get();
count.set(1);
count.set((v) => v + 1);
```

Units also support subscriptions and snapshots:

```ts
const unsub = count.subscribe((value) => {
  console.log('count changed', value);
});

const snap = count.snapshot();
unsub();
```

Common APIs:

- `get()`
- `set(next | updater)`
- `subscribe(fn)`
- `subscribeUpdate(fn)`
- `snapshot()`
- `reset()`

## Atomic State (Atom-like)

IO’s “atomic state” comes from `Unit`, while `Tree` lets you organize those atoms as a domain-shaped structure:

- **Unit = atom**: `io(0)` creates a standalone Unit you can subscribe to, update, and reuse.
- **Tree = atom factory**: `io({ ... })` expands objects/arrays; each path (especially leaves) is a Unit.
- **Structure stays intact**: you get atom-level subscriptions without giving up a coherent nested model.

```ts
import { io } from '@iostore/store';

const store = io({ user: { name: 'Ada' }, counter: 0 });

// Atomic Units
const name = store.user.name;
const counter = store.counter;

name.subscribe((v) => console.log('name', v));
counter.set((v) => v + 1);
```

## Scope (Objects)

When `io()` receives an object, it creates a Scope. Every key becomes a Unit.

```ts
const user = io({ name: 'Ada', age: 36 });

user.name.set('Grace');
user.age.set((v) => v + 1);
```

Scopes support `commit` for grouped updates:

```ts
user.commit((draft) => {
  draft.name = 'Lin';
  draft.age = 40;
});
```

## Arrays

Arrays are Tree nodes too and support common mutations.

```ts
const todos = io([{ id: 'a', done: false }]);

todos.push({ id: 'b', done: false });
todos[0].done.set(true);
```

:::caution
Avoid reusing the same object instance inside arrays.
:::

:::caution
`array.set([...])` replaces child units under the array. If a component subscribes to `array[index]`, it stays bound to the old unit and can appear stale.
Recommendation: update indices (`array[i].set(...)`) or subscribe to the array itself and read by index.
:::
