## Unit

A Unit is a function-like cell. Call it to read, call it with a value (or updater) to write.

```ts
import { oin } from '@oin/store';

const count = oin(0);

count(); // 0
count(1); // write
count((v) => v + 1); // update
```

Units expose:

- `subscribe(fn)` to listen to value changes
- `subscribeUpdate(fn)` to listen to update records
- `snapshot()` to get a frozen value

## Scope

When you pass an object to `oin`, you get a Scope with Units for each key.

```ts
const user = oin({ name: 'Ada', age: 36 });

user.name();
user.age(37);
```

Scopes also support grouped updates with `commit`:

```ts
user.commit((draft) => {
  draft.name = 'Grace';
  draft.age = 37;
});
```

## ArrayUnit

Arrays are first-class. Mutating helpers emit updates and keep paths stable.

```ts
const todos = oin([{ id: 'a', title: 'Ship', done: false }]);

todos.push({ id: 'b', title: 'Document', done: false });
todos[0].done(true);
```
