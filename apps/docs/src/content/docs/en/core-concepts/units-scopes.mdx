This page explains the two foundational shapes in IO: Units (values) and Scopes (objects).

## Unit

A Unit is the smallest writable cell with clear read/write APIs.

```ts
import { io } from 'io-store';

const count = io(0);

count.get();
count.set(1);
count.update((v) => v + 1);
```

Units also support subscriptions and snapshots:

```ts
const unsub = count.subscribe((value) => {
  console.log('count changed', value);
});

const snap = count.snapshot();
unsub();
```

Common APIs:

- `get()`
- `set(next)`
- `update(fn)`
- `subscribe(fn)`
- `subscribeUpdate(fn)`
- `snapshot()`
- `reset()`

## Scope (Objects)

When `io()` receives an object, it creates a Scope. Every key becomes a Unit.

```ts
const user = io({ name: 'Ada', age: 36 });

user.name.set('Grace');
user.age.update((v) => v + 1);
```

Scopes support `commit` for grouped updates:

```ts
user.commit((draft) => {
  draft.name = 'Lin';
  draft.age = 40;
});
```

## Arrays

Arrays are Tree nodes too and support common mutations.

```ts
const todos = io([{ id: 'a', done: false }]);

todos.push({ id: 'b', done: false });
todos[0].done.set(true);
```

:::caution
Avoid reusing the same object instance inside arrays.
:::
