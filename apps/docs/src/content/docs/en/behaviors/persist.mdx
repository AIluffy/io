Persist writes values to storage (defaults to `localStorage`).

## Basic Usage

```ts
import { io } from '@iostore/store';
import { persist, withBehaviors } from '@iostore/store/behavior';

const count = io(0);
const view = withBehaviors(count, [persist({ key: 'count' })]);
```

## Custom Storage

```ts
const memory = new Map<string, string>();

const view = withBehaviors(count, [
  persist({
    key: 'count',
    storage: {
      getItem: (key) => memory.get(key) ?? null,
      setItem: (key, value) => memory.set(key, value),
    },
  }),
]);
```

`storage.getItem/setItem` can be sync or async (`Promise`).

## Version Policy (Newest Wins)

```ts
persist({
  key: 'count',
  version: 2,
});
```

When persisted data has a different version than the current `version`, Persist ignores the old payload, keeps current in-memory state, and rewrites storage in the new version format.

## Partial Persistence

```ts
persist({
  key: 'profile',
  partialize: (value) => ({ token: (value as { token: string }).token }),
  merge: (persisted, current) => ({
    ...(current as Record<string, unknown>),
    ...(persisted as Record<string, unknown>),
  }),
});
```

## Throttled Writes

```ts
persist({
  key: 'count',
  throttleMs: 100,
});
```

## Cross-Tab Sync

```ts
persist({
  key: 'count',
  syncTabs: true,
});
```

## Serialization

```ts
persist({
  key: 'count',
  serialize: (value) => JSON.stringify(value),
  deserialize: (raw) => JSON.parse(raw),
});
```

## Notes

- Persist currently writes on `set()`.
- Functional updates are also written through `set((prev) => next)`.
- If you need immediate durability before page unload, keep `throttleMs` small.
