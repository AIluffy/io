Schedule coalesces or delays subscription notifications to reduce render thrash.

## Basic Usage

```ts
import { io } from '@iostore/store';
import { schedule, withBehaviors } from '@iostore/store/behavior';

const count = io(0);
const view = withBehaviors(count, [schedule('microtask')]);

view.subscribe((value) => {
  console.log('notified', value);
});
```

## Live Example

Try one burst write and compare notification counts for `sync` vs `microtask`.

```tsx live props={{ "client:load": true }}
import { useEffect, useState } from 'react';
import { io } from '@iostore/store';
import { schedule, withBehaviors } from '@iostore/store/behavior';

const syncStore = io(0);
const microtaskStore = io(0);
const syncView = withBehaviors(syncStore, [schedule('sync')]);
const microtaskView = withBehaviors(microtaskStore, [schedule('microtask')]);

function ScheduleLiveDemo() {
  const [runs, setRuns] = useState(0);
  const [syncNotifies, setSyncNotifies] = useState(0);
  const [microtaskNotifies, setMicrotaskNotifies] = useState(0);

  useEffect(() => {
    const offSync = syncView.subscribe(() => setSyncNotifies((n) => n + 1));
    const offMicrotask = microtaskView.subscribe(() =>
      setMicrotaskNotifies((n) => n + 1),
    );

    return () => {
      offSync();
      offMicrotask();
    };
  }, []);

  const burstUpdate = () => {
    setRuns((n) => n + 1);
    for (let i = 1; i <= 10; i += 1) {
      syncStore.set(i);
      microtaskStore.set(i);
    }
  };

  return (
    <section className="io-live">
      <div>For the same 10 writes:</div>
      <div>Run count: {runs}</div>
      <div>`schedule('sync')` cumulative notifications: {syncNotifies}</div>
      <div>`schedule('microtask')` cumulative notifications: {microtaskNotifies}</div>
      <button type="button" className="io-live__button" onClick={burstUpdate}>
        Run 10 consecutive set calls
      </button>
    </section>
  );
}

export default ScheduleLiveDemo;
```

Watch for this: `microtask` coalesces notifications in one tick, while `sync` emits per write.

## Strategies

- `sync`: notify immediately
- `microtask`: coalesce within the same tick
- `animationFrame`: notify before the next frame (if available)

## When to Use

- Frequent writes that can be delayed slightly
- UI jitter caused by many rapid updates
