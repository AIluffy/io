## Debounce notifications

The schedule behavior delays subscription notifications to reduce render churn.

```ts
import { oin } from '@oin/store';
import { schedule, withBehaviors } from '@oin/store/behavior';

const count = oin(0);
const view = withBehaviors(count, [schedule('microtask')]);

view.subscribe((value) => {
  console.log('notified', value);
});
```

## Schedule options

- `sync`: notify immediately
- `microtask`: coalesce within the current tick
- `animationFrame`: notify before next paint (if available)
