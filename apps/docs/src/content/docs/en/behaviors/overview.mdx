Behaviors wrap a view’s `get/set/subscribe` without changing the underlying Unit or tree. This makes it easy to add persistence, scheduling, or tooling.

```ts
import { io } from 'io-store';
import { persist, schedule, withBehaviors } from 'io-store/behavior';

const count = io(0);

const view = withBehaviors(count, [
  schedule('microtask'),
  persist({ key: 'count' }),
]);

view.subscribe((v) => console.log(v));
view.set?.(1);
view.get(); // read through the view
```

## Behavior types

- **Persist**: write-through to storage.
- **Schedule**: debounce subscriber notifications.
- **DevTools**: attach tooling instances.
