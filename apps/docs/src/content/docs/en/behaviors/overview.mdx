Behaviors add capabilities without changing the core API: persistence, scheduling, throttling, debouncing, side effects, DevTools, and more.

## Basic Usage

```ts
import { io } from '@iostore/store';
import {
  persist,
  schedule,
  throttle,
  effect,
  withBehaviors,
} from '@iostore/store/behavior';

const count = io(0);
const view = withBehaviors(count, [
  persist({ key: 'count' }),
  schedule('microtask'),
  throttle(50),
  effect((value) => console.log(value)),
]);

view.subscribe((value) => {
  console.log(value);
});
```

## IoView Interface

`withBehaviors` adapts nodes to an `IoView`:

- `get()` / `set()`
- `subscribe()` / `snapshot()`
- `extensions` for behavior instances
- `destroy()` for cleanup

## Composition Tips

- Apply `persist` before `schedule` or `devtools`.
- In high-frequency flows, place `throttle/debounce` before `effect`.
- Order matters when behaviors wrap each other.
