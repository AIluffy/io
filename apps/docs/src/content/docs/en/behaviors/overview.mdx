Behaviors add capabilities without changing the core API: persistence, scheduling, DevTools, and more.

## Basic Usage

```ts
import { io } from 'io-store';
import { persist, schedule, withBehaviors } from 'io-store/behavior';

const count = io(0);
const view = withBehaviors(count, [
  persist({ key: 'count' }),
  schedule('microtask'),
]);

view.subscribe((value) => {
  console.log(value);
});
```

## IoView Interface

`withBehaviors` adapts nodes to an `IoView`:

- `get()` / `set()` / `update()`
- `subscribe()` / `snapshot()`
- `extensions` for behavior instances
- `destroy()` for cleanup

## Composition Tips

- Apply `persist` before `schedule` or `devtools`.
- Order matters when behaviors wrap each other.
