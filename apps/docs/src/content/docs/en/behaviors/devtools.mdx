## Setup

```ts
import { io } from 'io-store';
import { createIoDevtools } from 'io-devtools';

const store = io({ counter: 0, user: { name: 'Ada' } });

const devtools = createIoDevtools(store, {
  name: 'IO Store',
  maxHistory: 200,
  captureSnapshots: 'always',
  perf: { enabled: true, windowSize: 60 },
});
```

## UI panel (React)

```tsx
import { createIoDevtools } from 'io-devtools';
import { IoDevtoolsPanel, IoDevtoolsErrorBoundary } from 'io-devtools-react';

export function DevtoolsDock({ devtools }: { devtools: ReturnType<typeof createIoDevtools> }) {
  return (
    <IoDevtoolsErrorBoundary>
      <IoDevtoolsPanel devtools={devtools} height={420} />
    </IoDevtoolsErrorBoundary>
  );
}
```

## Time travel

- `devtools.timeTravel.undo()` applies the inverted `update`.
- `devtools.timeTravel.redo()` replays the `update`.
- `devtools.timeTravel.goTo(index)` jumps to a cursor.

## Diffs

- **Patch diff**: derived from `update.patches`.
- **Snapshot diff**: available when `captureSnapshots: 'always'`.

## Export

```ts
const json = devtools.export.json();
const reduxImportState = devtools.export.reduxDevToolsImport();
```

## Behavior integration

To expose DevTools on the view node, attach it via behaviors:

```ts
import { devtools, withBehaviors } from 'io-store/behavior';
import { createIoDevtools } from 'io-devtools';
import { io } from 'io-store';

const store = io({ count: 0 });
const view = withBehaviors(store, [devtools({ target: store, create: createIoDevtools })]);
const dt = view.extensions?.devtools;
```
