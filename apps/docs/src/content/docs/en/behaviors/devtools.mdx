## Create an Instance

```ts
import { io } from '@iostore/store';
import { createIoDevtools } from '@iostore/devtools';

const store = io({ counter: 0, user: { name: 'Ada' } });

const devtools = createIoDevtools(store, {
  name: 'IO Store',
  maxHistory: 200,
  captureSnapshots: 'always',
  perf: { enabled: true, windowSize: 60 },
});
```

## React Panel

```tsx
import { IoDevtoolsPanel, IoDevtoolsErrorBoundary } from '@iostore/devtools-react';
import '@iostore/devtools-react/styles.css';

export function DevtoolsDock({ devtools }) {
  return (
    <IoDevtoolsErrorBoundary>
      <IoDevtoolsPanel devtools={devtools} height={420} />
    </IoDevtoolsErrorBoundary>
  );
}
```

### Styling and Theme

`IoDevtoolsPanel` expects its base stylesheet to be loaded:

```tsx
import '@iostore/devtools-react/styles.css';
```

You can customize the panel with CSS variables:

```css
.io-devtools-panel {
  --io-devtools-panel-bg: #0b1020;
  --io-devtools-surface: #111827;
  --io-devtools-text: #e5e7eb;
  --io-devtools-muted: #9ca3af;
  --io-devtools-border: #334155;
}
```

## Time Travel

- `devtools.timeTravel.undo()`
- `devtools.timeTravel.redo()`
- `devtools.timeTravel.goTo(index)`

## Diff

- **Patch diff**: from `update.patches`
- **Snapshot diff**: available with `captureSnapshots: 'always'`
- **Timeline label**: uses `update.action` first, then falls back to patch summary

## Export

```ts
const json = devtools.export.json();
const reduxImportState = devtools.export.reduxDevToolsImport();
```

## Behavior Integration

The `devtools()` behavior does not add new debugging features by itself.  
Core capabilities (time travel, diff, export, panel data) come from the instance created by `createIoDevtools(...)`.

Its role is to integrate that instance into the `withBehaviors()` pipeline for consistent wiring:

- Attach the instance to `view.extensions.devtools` (or a custom `key`)
- Compose it in the same way as other behaviors (`persist`, `schedule`)
- Auto-clean it via `devtools.destroy()` when `view.destroy()` is called

If you do not need unified behavior composition or lifecycle handling, calling `createIoDevtools(store, options)` directly is also valid.

```ts
import { devtools, withBehaviors } from '@iostore/store/behavior';
import { createIoDevtools } from '@iostore/devtools';
import { io } from '@iostore/store';

const store = io({ count: 0 });
const view = withBehaviors(store, [
  devtools({ target: store, create: createIoDevtools }),
]);

const dt = view.extensions?.devtools;
```
