Svelte integration is not enabled in this docs site (no `@astrojs/svelte`), so this page provides a minimal skeleton.

## Minimal Skeleton

Install dependencies:

```bash
pnpm -C apps/docs add @astrojs/svelte svelte
```

Enable Svelte in `astro.config.mjs`, then render as an island:

```astro
---
import Counter from '../components/Counter.svelte';
---

<Counter client:load />
```

## Notes

- Unsubscribe on component teardown to avoid leaks.
- Keep SSR output static; interactivity belongs in islands.
