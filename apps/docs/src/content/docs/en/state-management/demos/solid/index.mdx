Solid integration is not enabled in this docs site (no `@astrojs/solid`), so this page provides a minimal skeleton.

## Minimal Skeleton

Install dependencies:

```bash
pnpm -C apps/docs add @astrojs/solid solid-js
```

Enable Solid in `astro.config.mjs`, then render as an island:

```astro
---
import Counter from '../components/Counter.tsx';
---

<Counter client:load />
```

## Notes

- Keep stores and effects scoped to the island lifecycle.
- SSR output should stay static; interactivity belongs in islands.
