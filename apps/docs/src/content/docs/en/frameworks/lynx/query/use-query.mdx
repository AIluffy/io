  order: 2
---

```ts
import { useQuery } from '@iostore/lynx';

const users = useQuery({
  key: ['users'],
  queryFn: ({ signal }) => fetch('/api/users', { signal }).then((r) => r.json()),
});
```

- Put input params into `key`.
- Always pass `signal` to network requests.
- Distinguish `isLoading` (first load) and `isFetching` (includes refetch).
