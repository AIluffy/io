`@iostore/vue` provides both read-only and two-way binding styles that fit Vue ref semantics.

## When to Use

- Reading IO state in Vue components.
- Two-way input binding with IO units.
- Path-level subscription control for render efficiency.

## Minimal Integration

### useIO (read-only)

```ts
import { io } from '@iostore/store';
import { useIO } from '@iostore/vue';

const store = io({ count: 0 });
const state = useIO(store.count);
```

`useIO` returns `ShallowRef` for template consumption.

### ioRef (two-way binding)

```ts
import { ioRef } from '@iostore/vue';

const countRef = ioRef(store.count);
```

Use for `v-model` or interactive forms.

## Scheduling

```ts
const state = useIO(store.count, { schedule: 'microtask' });
```

Available: `sync` | `microtask` | `animationFrame`.

## API Quick Reference

| Scenario | API | Notes |
| --- | --- | --- |
| Read-only subscription | `useIO(unitOrDerived, options?)` | Returns a `ShallowRef` for display. |
| Two-way binding | `ioRef(unit, options?)` | Writable ref for `v-model` flows. |
| Notification scheduling | `options.schedule` | `sync`, `microtask`, `animationFrame`. |
| Path writes | `unit.set(next | updater)` | Keeps writes explicit and traceable. |
| Burst writes | `batch(fn)` | Reduces notification jitter. |

## Wrong vs Recommended

~~~ts
// Wrong: treating useIO result as writable
const count = useIO(store.count);
// count.value++

// Recommended: write via ioRef or set
const countRef = ioRef(store.count);
countRef.value += 1;
~~~

~~~ts
// Wrong: root-level subscription in component
const state = useIO(store);

// Recommended: path-level subscription
const count = useIO(store.count);
~~~

## Common Issues

- Treating `useIO` refs as writable data sources.
- Binding full root state instead of path units.
- High-frequency input without debounce/throttle.

## Practical Guidance

- Use `useIO` for display, `ioRef` for write-heavy input.
- Prefer path subscriptions over root subscriptions.
- Combine with [Schedule](/en/cookbook/schedule/) for notification cadence control.
