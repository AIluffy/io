## Client Frameworks vs SSR Frameworks

Client frameworks (React/Vue/Svelte/Solid/Lynx) focus on subscription granularity and render efficiency:

- Prefer path-level subscriptions over broad root subscriptions.
- Add equality guards for object selectors.
- Control update bursts with `batch` or `schedule`.

SSR frameworks (Next/Nuxt/SvelteKit) focus on runtime boundaries:

- Stores must be request-scoped, never process-global singletons.
- Hydration boundaries carry plain serializable data only.
- Reconstruct stores on the client before interactive behaviors.

## Common Integration Mistakes

- Subscribing broad root state in many leaf components.
- Reusing global stores across SSR requests.
- Mismatched initial-state shape across server/client hydration boundaries.
