## Overview

Extensions are behaviors that wrap a view’s `get/set/subscribe` without changing core OIN nodes.

```ts
import { oin } from '@oin/store';
import { withBehaviors, schedule, persist } from '@oin/store/behavior';

const count = oin(0);
const view = withBehaviors(count, [
  schedule('microtask'),
  persist({ key: 'count' }),
]);

view.subscribe((v) => console.log(v));
view(1); // view() reads, view(next) writes
```

## Full composition example

```ts
import { oin, lens } from '@oin/store';
import { withBehaviors, schedule, persist, devtools } from '@oin/store/behavior';
import { createOinDevtools } from '@oin/devtools';

const state = oin({
  user: { profile: { name: 'Ada', age: 36 } },
  prefs: { theme: 'light' },
});

const ageView = withBehaviors(lens<number>(state, ['user', 'profile', 'age']), [
  schedule('microtask'),
  persist({ key: 'user.age' }),
  devtools({ target: state, create: createOinDevtools }),
]);

ageView.subscribe((age) => console.log('age', age));
ageView((v) => v + 1);

const dt = ageView.extensions?.devtools;
```

## Notes

- `schedule` only affects subscription timing.
- `persist` stores values after `set`.
- `devtools` attaches a devtools instance to `view.extensions`.
- When the input is a tree node, `withBehaviors` keeps deep access (e.g. `view.user.age(2)`).
