## Access Control

- The docs site is static and cannot enforce reader authentication.
- Control writes via repo permissions, branch protection, and reviews.
- If reader auth is required, place the site behind an access gateway.

## Update Flow

- Treat `apps/docs/src/content/docs/**` as product code with PR review.
- Regenerate API references when public APIs change:

```bash
nx run apps-docs:generate-api
```

- Verify generated output:

```bash
git diff --exit-code apps/docs/src/content/docs
```

- Build the site locally:

```bash
nx run apps-docs:build
```

## CI Constraints

- CI regenerates API docs to prevent drift.
- Deployments run a full build to ensure the site is healthy.
