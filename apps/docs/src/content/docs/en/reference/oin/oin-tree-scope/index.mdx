## Signature

```ts
OinTreeScope<T, MaxDepth>
```

## Notes

- Used for deep object scopes (MaxDepth > 1); `OinScope` is the shallow alias.
- `commit` rejects unknown keys to keep the scope shape stable.

| Name | Type |
| --- | --- |

| snapshot | `() => T` |
| subscribe | `(fn: (v: T) => void) => OinUnsubscribe` |
| subscribeUpdate | `(fn: (u: OinUpdate) => void) => OinUnsubscribe` |
