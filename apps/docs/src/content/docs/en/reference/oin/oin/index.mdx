## Signature

```ts
<T>(initial: T, options?: { silent?: boolean }) => OinResult<T>
```

`oin()` deep-processes objects and arrays by default (legacy `oinTree()` / `oinDeep()` behavior). Use `oinShallow()` for legacy shallow objects.

## Parameters

| Name | Type |
| --- | --- |
| initial | `T` |

## Returns

`OinResult<T>`

## Errors

- This library does not define standardized error codes.
- Mutations can report failures through `onError(listener)` (operation, path, value).

## Authentication

- Not applicable. OIN is a local TypeScript/JavaScript library and does not implement authentication.
