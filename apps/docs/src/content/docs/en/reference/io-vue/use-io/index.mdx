## When to Use

Use this function when you need this behavior from the package API.

## Signature

```ts
<T>(source: IoSource<T>, options?: IoVueOptions) => ShallowRef<T>
```

## Parameters

| Name | Type |
| --- | --- |
| source | `IoSource<T>` |
| options | `IoVueOptions` |

## Returns

`ShallowRef<T>`

## Minimal Example

```ts
import { useIO } from '@iostore/vue';

const result = useIO(/* ...args */);
console.log(result);
```

## Common Pitfalls

- Validate argument types and nullability before calling.
- Confirm import path and runtime environment (server/client) expectations.
