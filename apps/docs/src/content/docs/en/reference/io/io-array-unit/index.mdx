## Signature

```ts
IoArrayUnit<T>
```

## Notes

- Alias of `IoTreeArrayUnit<T, 1>` (shallow depth).
- Implemented by the same tree engine; there is no separate array-unit runtime.
- `set()` replaces the entire array and emits a `set` patch for the array path.

## Errors

- This library does not define standardized error codes.
- Mutations can report failures through `onError(listener)` (operation, path, value).
