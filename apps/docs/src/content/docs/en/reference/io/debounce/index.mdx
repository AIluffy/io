---
title: "debounce"
description: "Behavior API: emit after inactivity window."
---

## When to Use

- Search-like inputs where only the final value matters.
- Merge burst updates and avoid redundant side effects.

## Signature

```ts
<T>(waitMs: number, options?: DebounceBehaviorOptions) => IoBehavior<T>
```

## Parameters

| Name | Type |
| --- | --- |
| waitMs | `number` |
| options | `DebounceBehaviorOptions` |

## Returns

`IoBehavior<T>`

## Minimal Example

```ts
import { io } from '@iostore/store';
import { debounce, withBehaviors } from '@iostore/store/behavior';

const keyword = io('');
const view = withBehaviors(keyword, [debounce(200)]);
```

## Common Pitfalls

- Adding `debounce` but still triggering expensive work synchronously upstream.
- Setting `waitMs` too high and making interactions feel laggy.
