## Signature

```ts
IoScope<T>
```

## Notes

- Alias of `IoTreeScope<T, 1>` (shallow depth).
- `commit` rejects unknown keys to keep the scope shape stable.

## Properties

| Name | Type |
| --- | --- |
| commit | `(fn: (draft: T) => void) => void` |
| snapshot | `() => T` |
| subscribe | `(fn: (v: T) => void) => IoUnsubscribe` |
| subscribeUpdate | `(fn: (u: IoUpdate) => void) => IoUnsubscribe` |

## Errors

- This library does not define standardized error codes.
- Mutations can report failures through `onError(listener)` (operation, path, value).
