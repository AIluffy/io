## When to Use

Create an IO node from any value.

## Signature

```ts
<T>(target: T, options: { shallow: true; }) => IoNode<T>
```

## Parameters

| Name | Type |
| --- | --- |
| target | `T` |
| options | `{ shallow: true; }` |

## Returns

`IoNode<T>`

## Minimal Example

```ts
import { io } from '@iostore/store';

const result = io(/* ...args */);
console.log(result);
```

## Common Pitfalls

- Validate argument types and nullability before calling.
- Confirm import path and runtime environment (server/client) expectations.
