This guide maps typical Zustand patterns to IO with an emphasis on semantic equivalence.

## Create a Store

Zustand:

```ts
const useStore = create((set) => ({
  count: 0,
  inc: () => set((s) => ({ count: s.count + 1 })),
}));
```

IO:

```ts
import { io } from '@iostore/store';

const store = io({ count: 0 });
const inc = () => store.count.set((v) => v + 1);
```

## Selectors

Zustand:

```ts
const count = useStore((s) => s.count);
```

IO (derived):

```ts
import { derived } from '@iostore/store';

const count = derived(store, (s) => s.count);
```

## Middleware → Behaviors

```ts
import { persist, devtools, withBehaviors } from '@iostore/store/behavior';
import { createIoDevtools } from '@iostore/devtools';

const view = withBehaviors(store, [
  persist({ key: 'store' }),
  devtools({ target: store, create: createIoDevtools }),
]);
```

## React Usage

```tsx
import { useIO } from '@iostore/react';

function Counter() {
  const value = useIO(store.count);
  return <button onClick={inc}>{value}</button>;
}
```

## Shallow Mode

If you only need the first level to be Units:

```ts
const shallow = io({ count: 0 }, { shallow: true });
```
