This guide maps popular Zustand patterns to IO equivalents. The goal is clarity, not a 1:1 API match.

## Store creation

Zustand:

```ts
const useStore = create((set) => ({
  count: 0,
  inc: () => set((s) => ({ count: s.count + 1 })),
}));
```

IO:

```ts
import { io } from 'io-store';

const store = io({ count: 0 });
const inc = () => store.count((v) => v + 1);
```

If you prefer “shallow” shape-only stores, use `shallow: true`. Shallow mode limits depth to 1 and rejects unknown keys in `commit`.

## Selectors

Zustand selector:

```ts
const count = useStore((s) => s.count);
```

IO selector via derived:

```ts
import { derived } from 'io-store';

const count = derived(store, (s) => s.count);
```

For path-focused access, use `focus`:

```ts
import { focus } from 'io-store';

const userName = focus<string>(store, ['user', 'name']);
```

## Middleware → Behaviors

Zustand middlewares like `persist` and `devtools` map to IO behaviors.

```ts
import { persist, devtools, withBehaviors } from 'io-store/behavior';
import { createIoDevtools } from 'io-devtools';

const view = withBehaviors(store, [
  persist({ key: 'store' }),
  devtools({ target: store, create: createIoDevtools }),
]);
```

## React usage

Zustand `useStore` becomes `useIo`:

```tsx
import { useIo } from 'io-react';

function Counter() {
  const value = useIo(store.count);
  return <button onClick={inc}>{value}</button>;
}
```
