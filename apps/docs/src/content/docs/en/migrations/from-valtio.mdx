This guide translates common Valtio usage to IO with explicit Units and snapshots.

## Create Store State

Valtio:

```ts
import { proxy } from 'valtio';

const state = proxy({ count: 0, user: { name: 'Ada' } });
```

IO:

```ts
import { io } from 'io-store';

const store = io({ count: 0, user: { name: 'Ada' } });
```

## Read Reactive Snapshot in React

Valtio:

```tsx
import { useSnapshot } from 'valtio';

const snap = useSnapshot(state);
```

IO:

```tsx
import { useIO } from 'io-react';

const count = useIO(store.count);
const name = useIO(store.user.name);
```

## Mutations

Valtio:

```ts
state.count += 1;
state.user.name = 'Grace';
```

IO:

```ts
store.count.set((v) => v + 1);
store.user.name.set('Grace');
```

## Batch Complex Changes

```ts
store.commit((draft) => {
  draft.count += 1;
  draft.user.name = 'Lin';
});
```
