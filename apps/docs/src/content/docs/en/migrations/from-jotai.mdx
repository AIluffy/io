This guide maps common Jotai patterns to IO while preserving update semantics.

## Primitive Atoms

Jotai:

```ts
import { atom } from 'jotai';

export const countAtom = atom(0);
```

IO:

```ts
import { io } from '@iostore/store';

export const count = io(0);
```

## Derived Values

Jotai:

```ts
const doubleAtom = atom((get) => get(countAtom) * 2);
```

IO:

```ts
import { derived } from '@iostore/store';

const double = derived([count], (v) => v * 2);
```

## Writable Derived Logic

Jotai:

```ts
const incAtom = atom(null, (_get, set) => {
  set(countAtom, (v) => v + 1);
});
```

IO:

```ts
const inc = () => count.set((v) => v + 1);
```

## React Usage

Jotai:

```tsx
const [count, setCount] = useAtom(countAtom);
```

IO:

```tsx
import { useIO } from '@iostore/react';

function Counter() {
  const value = useIO(count);
  return <button onClick={() => count.set((v) => v + 1)}>{value}</button>;
}
```
