This guide shows how Redux-style state updates map to IO primitives.

## Store + Reducer

Redux:

```ts
type State = { count: number };
type Action = { type: 'inc' } | { type: 'set'; payload: number };

function reducer(state: State = { count: 0 }, action: Action): State {
  switch (action.type) {
    case 'inc':
      return { ...state, count: state.count + 1 };
    case 'set':
      return { ...state, count: action.payload };
    default:
      return state;
  }
}
```

IO:

```ts
import { io } from '@iostore/store';

const store = io({ count: 0 });

const inc = () => store.count.set((v) => v + 1);
const setCount = (value: number) => store.count.set(value);
```

## Dispatching Multiple Field Updates

Redux often coordinates this in a reducer. In IO, use `commit`:

```ts
const user = io({ name: 'Ada', age: 18 });

const updateProfile = (name: string, age: number) => {
  user.commit((draft) => {
    draft.name = name;
    draft.age = age;
  });
};
```

## Time-Travel Style Undo/Redo

```ts
import { createHistory } from '@iostore/store';

const history = createHistory(store);
history.undo();
history.redo();
```

## React Usage

```tsx
import { useIO } from '@iostore/react';

function Counter() {
  const value = useIO(store.count);
  return <button onClick={inc}>{value}</button>;
}
```
