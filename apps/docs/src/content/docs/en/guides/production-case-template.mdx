Use this page to produce repeatable “production case” assets for internal sharing and external promotion.

```md
## 4. Rollout Steps
1. Adapter + baseline behavior integration

3. Regression validation + staged rollout

## 5. Outcome Metrics (before/after)

- Render count:
- Error rate:
- Delivery lead time:

## 6. Issues and Rollback
- Issues encountered:
- How they were resolved:
- Rollback plan:

## 7. Reuse Guidance
- Best-fit business scenarios:
- Scenarios not recommended:
```

## B. 10-Minute Decision Sheet

Score each question from 0 to 2. Total score >= 8 usually indicates IO priority.

| Question | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Deep-state complexity | flat/simple | medium | deep/complex |
| Replay/undo/audit need | none | occasional | strong |
| Multi-framework collaboration | single framework | 2 frameworks | >= 3 frameworks |
| Migration window | very short | phased | planned migration |
| Perf bottleneck source | not state-related | partly state-related | state-update dominant |

## C. Minimum Release Evidence

- Change scope (modules/files)
- Regression matrix results (P0/P1)
- Production observation window (>= 24h)
- Severity log summary (SEV counts)
