IO ships with strong inference, but you can also use exported types for precision.

## Inference Example

```ts
import { io } from '@iostore/store';

const store = io({ count: 0, user: { name: 'Ada' } });

store.count.get();
store.user.name.set('Lin');
```

## Common Types

- `IoUnit<T>`
- `IoNode<T>`
- `IoScope<T>`
- `IoUpdate` / `IoPatch`
- `IoPathOf<T>` / `IoPathValue<T, P>`
- `UnwrapIo<T>`

## Type Helper Example

```ts
import type { IoPathOf, IoPathValue } from '@iostore/store';

type Store = { user: { name: string }; count: number };

type Path = IoPathOf<Store>;

type NameValue = IoPathValue<Store, ['user', 'name']>;
```

## Guidance

- Use `io()` inference by default.
- Add explicit types only for cross-layer APIs.
