## Typed Units

```ts
import type { IoUnit } from 'io-store';
import { io } from 'io-store';

const count: IoUnit<number> = io(0);
```

## Typed trees

`io()` preserves nested shapes, so property access is strongly typed.

```ts
const store = io({ user: { name: 'Ada', age: 36 } });
store.user.name.get();
```

## Path helpers

Use path helpers for utilities and adapters.

```ts
import type { IoPathOf, IoPathValue } from 'io-store';

type Store = { user: { profile: { name: string } } };

type NamePath = IoPathOf<Store>; // ['user', 'profile', 'name'] | ...

type NameValue = IoPathValue<Store, ['user', 'profile', 'name']>; // string
```

## Unwrap helpers

```ts
import type { UnwrapIo } from 'io-store';

const store = io({ user: { profile: { name: 'Ada' } } });
type Shape = UnwrapIo<typeof store>;
```
