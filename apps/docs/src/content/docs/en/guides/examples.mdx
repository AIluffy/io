## Run with Nx (recommended)

Run these from the repo root:

```bash
nx run io-example-core-node:start
nx run io-example-react-vite:dev
nx run io-example-vue-vite:dev
nx run io-example-svelte-vite:dev
```

## Example app paths

- Core (Node): `examples/core-node`
- React (Vite): `examples/react-vite`
- Vue (Vite): `examples/vue-vite`
- Svelte (Vite): `examples/svelte-vite`

## Manual run (per example)

```bash
cd examples/react-vite
npm install
npm run dev
```
