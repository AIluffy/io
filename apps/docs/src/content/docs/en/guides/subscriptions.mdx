## Value subscriptions

```ts
import { io } from 'io-store';

const count = io(0);

const unsub = count.subscribe((value) => {
  console.log('value', value);
});

count.set(1);
unsub();
```

Use value subscriptions for UI rendering and anything that needs the latest value.

## Update subscriptions

`subscribeUpdate` gives you structured patches.

```ts
const unsubUpdate = count.subscribeUpdate((update) => {
  for (const patch of update.patches) {
    console.log(patch.op, patch.path, patch.next);
  }
});
```

Use update subscriptions for logging, persistence, syncing, and devtools.

## Scope and tree bubbling

Subscriptions bubble through tree nodes, so subscribing at the root will capture nested changes.

```ts
const store = io({ user: { name: 'Ada' } });

store.subscribe(() => {
  console.log('root value changed', store.snapshot());
});

store.subscribeUpdate((u) => {
  console.log('root patches', u.patches);
});
```

## Cleanup

Always call the unsubscribe function (React effect cleanup, Vue scope dispose, Svelte onDestroy, etc.).
