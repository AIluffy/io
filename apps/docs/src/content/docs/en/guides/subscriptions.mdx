## Value subscriptions

```ts
import { io } from 'io-store';

const count = io(0);

const unsub = count.subscribe((value) => {
  console.log('value', value);
});

count.set(1);
unsub();
```

## Update subscriptions

`subscribeUpdate` gives you structured patches.

```ts
const unsubUpdate = count.subscribeUpdate((update) => {
  for (const patch of update.patches) {
    console.log(patch.op, patch.path, patch.next);
  }
});
```

## Scope and tree bubbling

Subscriptions bubble through tree nodes, so subscribing at the root will capture nested changes.
