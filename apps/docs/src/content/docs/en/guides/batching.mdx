## Why batch

Batching coalesces notifications and merges patches into a single update, which is great for UI performance and DevTools history.

```ts
import { batch, oin } from '@oin/store';

const store = oin({ count: 0, name: 'Ada' });

batch(() => {
  store.count((v) => v + 1);
  store.name('Grace');
});
```

## Nested batches

Batches can be nested. OIN only flushes once at the outer boundary.
