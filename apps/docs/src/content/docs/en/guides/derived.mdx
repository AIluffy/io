Derived values are read-only nodes computed from other state. Use them for totals, view models, and derived flags.

<DerivedRecipe />

## Choose a style

- Use `derived([deps], compute)` when you know the exact inputs.
- Use `derived(tree, selector)` when you want to “select” from a tree.
- Use `derived(() => ...)` when you want to read via `get()` and let IO track dependencies.

## From explicit deps

```ts
import { derived, io } from 'io-store';

const count = io(1);
const doubled = derived([count], (value) => value * 2);

doubled.get(); // 2
```

## From a tree selector

```ts
const store = io({ pricing: { price: 10, tax: 2 } });

const total = derived(store, (s) => s.pricing.price + s.pricing.tax);
```

## From a computed function

```ts
const combined = derived(() => count.get() + doubled.get());
```

## Gotchas

- Derived values are read-only. To change state, update the underlying Units.
- Subscriptions keep derived values “live”. Always unsubscribe when you no longer need updates.
