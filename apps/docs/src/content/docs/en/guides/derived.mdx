Derived values are read-only computations that update when dependencies change.

## Option 1: Explicit Dependencies

```ts
import { derived, io } from 'io-store';

const count = io(0);
const doubled = derived([count], (value) => value * 2);
```

If your state comes from a Tree, you can also pass “path Units” as atom-like dependencies:

```ts
import { derived, io } from 'io-store';

const store = io({ user: { name: 'Ada' }, count: 0 });
const summary = derived(
  [store.user.name, store.count],
  (name, count) => `${name} · ${count}`,
);
```

## Option 2: Tree Selector

```ts
const store = io({ count: 0, user: { name: 'Ada' } });

const summary = derived(store, (s) => `${s.user.name} · ${s.count}`);
```

## Option 3: Auto Tracking

```ts
const store = io({ count: 0, rate: 2 });

const total = derived(() => store.count.get() * store.rate.get());
```

## Why Not Implicit Auto Tracking

`derived()` offers three options to keep dependency semantics explicit:

- **Explicit deps**: subscriptions come from the provided dependencies.
- **Tree selector**: subscriptions come from the provided tree node (not the selector’s access paths).
- **Auto tracking**: dependencies come from runtime `get()` reads.

If these were merged into implicit auto tracking, dependency sources would be opaque,
which makes subscription scope, performance, and debugging harder to reason about.
IO keeps the semantics explicit and limits “auto tracking” to `derived(() => ...)`.

## Subscribe

```ts
const stop = doubled.subscribe((value) => {
  console.log(value);
});
```

## Case: Run a Function from Multiple Stores / Keys

When you want to run a function whenever any dependency changes, compose a `derived` and subscribe to it:

```ts
import { batch, derived, io } from 'io-store';

const user = io({ age: 18, level: 1 });
const order = io({ amount: 99 });

const trigger = derived(
  [user.age, user.level, order.amount],
  (age, level, amount) => ({ age, level, amount }),
);

const run = ({
  age,
  level,
  amount,
}: {
  age: number;
  level: number;
  amount: number;
}) => {
  // Your business function
  console.log('run with', { age, level, amount });
};

// If needed, run once on init
run(trigger.get());

const stop = trigger.subscribe(run);

// Use batch when multiple deps change in one transaction
batch(() => {
  user.age.set(19);
  order.amount.set(199);
});
```

## Notes

- Derived values are read-only.
- Reads via `get()` participate in dependency tracking.
- Split heavy chains into smaller derived values for clarity.
