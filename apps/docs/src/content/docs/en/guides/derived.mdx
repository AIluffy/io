Derived values are read-only computations that update when dependencies change.

## Option 1: Explicit Dependencies

```ts
import { derived, io } from 'io-store';

const count = io(0);
const doubled = derived([count], (value) => value * 2);
```

## Option 2: Tree Selector

```ts
const store = io({ count: 0, user: { name: 'Ada' } });

const summary = derived(store, (s) => `${s.user.name} · ${s.count}`);
```

## Option 3: Auto Tracking

```ts
const store = io({ count: 0, rate: 2 });

const total = derived(() => store.count.get() * store.rate.get());
```

## Subscribe

```ts
const stop = doubled.subscribe((value) => {
  console.log(value);
});
```

## Notes

- Derived values are read-only.
- Reads via `get()` participate in dependency tracking.
- Split heavy chains into smaller derived values for clarity.
