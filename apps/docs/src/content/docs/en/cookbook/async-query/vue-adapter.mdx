## What It Is

The Vue adapter exposes query state in a Vue-friendly reactive shape for Composition API workflows.

## When to Use

- Vue pages need unified query + mutation behavior.
- You need reactive state composition around query lifecycle.

## Core API

- [useQuery](/en/api-reference/io-vue/use-query/)
- [io-vue-query-result](/en/api-reference/io-vue/io-vue-query-result/)

## Minimal Example

```ts
import { computed } from 'vue';
import { useQuery } from '@iostore/vue';

const users = useQuery({
  key: ['users', keyword.value],
  queryFn: ({ signal }) =>
    fetch(`/api/users?keyword=${keyword.value}`, { signal }).then((r) => r.json()),
});

const isReady = computed(() => !users.isFetching.value && !users.error.value);
```

## Common Pitfalls

- Key does not include reactive inputs.
- Keeping page query state outside setup lifecycle boundary.
- Missing cancellation strategy in rapid switches.

## Practical Guidance

- Keep readiness gating and key params aligned.
- Forward `signal` from every request function.
- Invalidate after writes instead of guessing cache patches.
