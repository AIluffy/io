## What It Is

The React adapter maps query state machines into hook results aligned with React rendering semantics.

## When to Use

- You need declarative query + mutation flow in React components.
- You need explicit loading/error/success handling in UI.

## Core API

- [useQuery](/en/api-reference/io-react/use-query/)
- [useMutation](/en/api-reference/io-react/use-mutation/)
- [useSuspenseQuery](/en/api-reference/io-react/use-suspense-query/)

## Minimal Example

```tsx
import { useMutation, useQuery } from '@iostore/react';

const todos = useQuery({
  key: ['todos'],
  queryFn: ({ signal }) => fetch('/api/todos', { signal }).then((r) => r.json()),
});

const addTodo = useMutation({
  mutationFn: (title: string) =>
    fetch('/api/todos', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ title }),
    }).then((r) => r.json()),
  onSuccess: () => todos.query.invalidate(),
});
```

## Common Pitfalls

- Ignoring `signal` in query functions.
- Surfacing `AbortError` as user-visible business failure.
- Reusing one client where route-level isolation is needed.

## Practical Guidance

- Skip `client` option by default; pass one only for explicit isolation.
- Use invalidation as the default post-write action.
- Pair Suspense flows with ErrorBoundary.
