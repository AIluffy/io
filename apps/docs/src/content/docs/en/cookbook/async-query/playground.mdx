## What It Is

This Playground is an interactive Query sandbox that demonstrates `useQuery`, `useMutation`, invalidation, cancellation, and retry behavior.

## When to Use

- You need to validate query lifecycle behavior quickly.
- You want to demo failure -> retry -> recovery to your team.
- You need a reproducible scenario for cancellation and fast switching.

## Suggested Interactions

- Turn on teaching mode and follow the guided failure-recovery steps.
- Switch failure mode and compare retry count 0 vs 2 behavior.
- Trigger cancellation and confirm it is control flow, not a business failure.
