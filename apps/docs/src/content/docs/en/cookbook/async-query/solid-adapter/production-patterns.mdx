## Infinite Query and Window Control

```tsx
import { useInfiniteQuery } from '@iostore/solid';

const feed = useInfiniteQuery({
  key: ['feed', 'home'],
  initialPageParam: null as string | null,
  queryFn: ({ signal, pageParam }) =>
    fetch('/api/feed?cursor=' + (pageParam ?? ''), { signal }).then((r) => r.json()),
  getNextPageParam: (lastPage) => lastPage.nextCursor ?? null,
  maxPages: 5,
  cancelOnDispose: true,
});
```

- Use `maxPages` to cap in-memory window and avoid unbounded accumulation.
- Check `isFetchingNextPage` before triggering load-more on scroll end.
- Enable cancellation by default for high-frequency list switching.

## Prefetch, Retry, and Performance

1. Run `prefetch` before route transitions to reduce first-render wait.
2. Use bounded retries (1-2) for network jitter; do not retry business failures.
3. Use `select` to trim render payload and reduce unrelated updates.
4. Handle cancellation uniformly and exclude `AbortError` from alert pipelines.
