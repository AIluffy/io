## 5.1 Standard page-based pagination

Use this for deterministic page numbers (`page=1,2,3...`):

```ts
const current = client.defineQuery({
  key: ['users', { page, pageSize }],
  queryFn: ({ signal }) => fetch(`/api/users?page=${page}&pageSize=${pageSize}`, { signal }).then((r) => r.json()),
});
```

Guidelines:

- Include page params in the key.
- Prefetch only when `hasMore` is true.

## 5.2 Infinite Query prefetch and cancellation

Use this for endless loading:

```ts
await client.prefetchInfiniteQuery(
  {
    key: ['feed'],
    initialPageParam: 0,
    queryFn: ({ signal, pageParam }) =>
      fetch(`/api/feed?cursor=${pageParam}`, { signal }).then((r) => r.json()),
    getNextPageParam: (lastPage) => lastPage.nextCursor,
  },
  3,
);
```

- The second parameter controls how many pages to prefetch (`3` in this example).
- `cancel()` aborts in-flight fetch and resets direction state.

## Choosing strategy

- **Numbered pages**: `defineQuery` + prefetch next page.
- **Infinite feed**: `defineInfiniteQuery` / `useInfiniteQuery`.
