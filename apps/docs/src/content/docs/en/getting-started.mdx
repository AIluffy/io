## Installation

<Steps>

1.  Install the core package:

    ```bash
    npm install @oin/store
    ```

2.  Install your framework adapter (optional):

    ```bash
    npm install @oin/react
    ```

</Steps>

## First State

```ts
import { oin } from '@oin/store';

const count = oin(0);

count();          // read
count(1);         // write
count((v) => v + 1);
```

## Deep By Default

`oin()` deep-processes objects and arrays by default, so nested properties can be updated as leaf units without switching APIs.

```ts
import { oin } from '@oin/store';

const user = oin({ profile: { name: 'Ada' } });

user.profile.name();        // "Ada"
user.profile.name('Grace'); // write at path ["profile","name"]
```

If you need the legacy “shallow first-level only” behavior, use `oinShallow()`. `oinTree()` / `oinDeep()` are deprecated but still available.
