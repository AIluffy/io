## Signature

```ts
<TData, TError = Error>(options: IoQueryOptions<TData, TError> & { client?: IoQueryClient; enabled?: boolean; cancelOnDispose?: boolean }) => IoVueQueryResult<TData, TError>
```

## Notes

- `options.client` is optional.
- If omitted, useQuery uses [getDefaultClient](/en/api-reference/io-query/get-default-client/).
- Pass a custom `client` only for request-scoped SSR, test isolation, or multiple cache domains.

## Returns

`IoVueQueryResult<TData, TError>`
