## Minimal Example

```ts
import type { IoHistoryOptions } from '@iostore/store/patches';

let value!: IoHistoryOptions;
console.log(value);
```

## Field Notes

- `limit`: maximum history length, default `Infinity`.
- `emitUpdate`: emit replayed updates during undo/redo, default `true`.
- `filter`: record strategy, default `exclude-undo-redo`.
- `groupBy`: group-key function for contiguous updates.

## Common Pitfalls

- Returning unstable object references in `groupBy`.
- Over-filtering updates and ending up with an empty history.
