`useResource` has been removed.

Use `useQuery` with `@iostore/store/query` instead:

- Create or reuse a query via `client.query({ key, queryFn, ... })`
- Consume it with framework adapters (`useQuery` / `createQueryStore`)

`createResource` and `IoResource*` types are no longer part of the current API.
