## When to Use

Use this function when you need this behavior from the package API.

## Signature

```ts
<TData>(resource: IoResource<TData>, options?: IoUseResourceOptions) => IoQueryResult<TData>
```

## Parameters

| Name | Type |
| --- | --- |
| resource | `IoResource<TData>` |
| options | `IoUseResourceOptions` |

## Returns

`IoQueryResult<TData>`

## Minimal Example

```ts
import { useResource } from '@iostore/react';

const result = useResource(/* ...args */);
console.log(result);
```

- Validate argument types and nullability before calling.
- Confirm import path and runtime environment (server/client) expectations.
