## What it does

Reads Infinite Query inside a Suspense boundary. When data is not ready, it throws a Promise for fallback rendering.

## Signature

```ts
<TData, TError = Error, TPageParam = unknown, TSelected = InfiniteData<TData, TPageParam>>(
  options: UseInfiniteQueryOptions<TData, TError, TPageParam, TSelected>,
  suspenseOptions?: { useReactUseHook?: boolean },
) => UseSuspenseInfiniteQueryResult<TData, TError, TPageParam, TSelected>
```

## Usage notes

- Pair with ErrorBoundary.
- Useful when multi-page data is required before render.
