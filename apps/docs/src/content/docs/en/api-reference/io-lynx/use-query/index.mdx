## Signature

```ts
<TData, TError = Error>(options: IoQueryOptions<TData, TError> & { client?: IoQueryClient; enabled?: boolean; cancelOnUnmount?: boolean }) => IoLynxQueryResult<TData, TError>
```

## Notes

- `options.client` is optional.
- If omitted, useQuery uses [getDefaultClient](/en/api-reference/io-query/get-default-client/).
- Pass a custom `client` only for request-scoped SSR, test isolation, or multiple cache domains.
- Adapter-triggered lifecycle fetches use `query.fetchQuietly()` internally.

## Returns

`IoLynxQueryResult<TData, TError>`
