## When to Use

Use this type alias to model reusable type shapes.

## Signature

```ts
IoResource<TData>
```

## Properties

| Name | Type |
| --- | --- |
| key | `unknown` |
| read | `() => TData \| undefined` |
| getState | `() => IoQueryState<TData>` |
| fetch | `(options?: IoResourceRequestOptions) => Promise<TData>` |
| prefetch | `(options?: IoResourceRequestOptions) => Promise<void>` |
| invalidate | `(options?: { action?: string; meta?: Record<string, unknown>; }) => number` |
| cancel | `() => number` |
| subscribe | `(listener: (state: IoQueryState<TData>) => void) => Unsubscribe` |

## Minimal Example

```ts
import type { IoResource } from '@iostore/query';

let value!: IoResource;
console.log(value);
```

## Common Pitfalls

- Avoid over-expanding complex aliases in user-facing docs.
- Keep aliases stable to prevent downstream type breakage.
