## When to Use

Use `hashKey` for debugging query cache identity and deterministic key comparisons.

## Signature

```ts
function hashKey(key: IoQueryKey): string;
```

## Minimal Example

```ts
const hash = hashKey(['users', { page: 1 }]);
console.log(hash);
```

## Common Pitfalls

- Passing non-serializable values (function/symbol/circular refs) throws.
