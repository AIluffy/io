## When to Use

Use this type alias to model reusable type shapes.

## Signature

```ts
IoQueryOptions<TData = unknown, TError = Error>
```

## Minimal Example

```ts
import type { IoQueryOptions } from '@iostore/store/query';

let value!: IoQueryOptions;
console.log(value);
```

## Common Pitfalls

- Avoid over-expanding complex aliases in user-facing docs.
- Keep aliases stable to prevent downstream type breakage.
- `key` must be stably serializable: no `function`, no `symbol`, and no circular references.
- Forward `signal` inside `queryFn` to actually cancel in-flight network calls.
