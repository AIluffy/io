---
title: "IoUnsubscribe"
description: "Function type used to dispose subscriptions."
---

## When to Use

Use this type for values returned by `subscribe(...)` APIs.

## Signature

```ts
type IoUnsubscribe = () => void;
```

## Minimal Example

```ts
const unsub: IoUnsubscribe = query.subscribe(() => {
  console.log(query.snapshot());
});
unsub();
```

## Common Pitfalls

- Forgetting to call unsubscribe in long-lived effects.
