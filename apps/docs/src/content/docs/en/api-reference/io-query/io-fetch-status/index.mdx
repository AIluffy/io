description: "Fetch-axis status union for query state."
---

## When to Use

Use this type to model whether a query request is currently in flight.

## Signature

```ts
type IoFetchStatus = 'idle' | 'fetching';
```

## Minimal Example

```ts
const isFetching = state.fetchStatus === 'fetching';
```

## Common Pitfalls

- Reading only `fetchStatus` and ignoring `status` can blur first-load vs refetch semantics.
