## When to Use

Use `createMutation` for write operations with retry, optimistic context, cancellation, and lifecycle callbacks.

## Signature

```ts
function createMutation<
  TData = unknown,
  TVariables = void,
  TError = Error,
  TContext = unknown,
>(
  options: IoMutationOptions<TData, TVariables, TError, TContext>,
): IoMutation<TData, TVariables, TError>;
```

## Parameters

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `options` | `IoMutationOptions<TData, TVariables, TError, TContext>` | Yes | — | Mutation function, retry policy, and lifecycle callbacks. |

## Returns

`IoMutation<TData, TVariables, TError>`

## Minimal Example

```ts
const mutation = createMutation({
  mutationFn: (title: string) =>
    fetch('/api/todos', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ title }),
    }).then((r) => r.json()),
  retry: 1,
});

const created = await mutation.mutateAsync('Ship docs update');
console.log(created);
```

## Common Pitfalls

- Doing optimistic cache writes without rollback data from `onMutate` context.
- Treating cancellation as a business failure condition.
- Forgetting to expose `mutation.flags` in UI state.
