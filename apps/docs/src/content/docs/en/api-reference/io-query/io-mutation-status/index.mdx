## When to Use

Use this type to model mutation lifecycle stages.

## Signature

```ts
type IoMutationStatus = 'idle' | 'pending' | 'success' | 'error';
```

## Minimal Example

```ts
if (mutation.snapshot().status === 'pending') {
  showSpinner();
}
```

## Common Pitfalls

- Treating `success` as persistent truth after a new mutation starts.
