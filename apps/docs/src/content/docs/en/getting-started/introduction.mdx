IO is a TypeScript state library for apps that want “deep state, no drama.” You change a nested field directly, subscribe precisely to what you use, and keep rendering work small. Every write also produces patches you can inspect, replay, or undo.

Start here:

`io()` creates state, `derived()` creates computed values, and `batch()` groups multiple writes into one notification.

## Mental model

- **Unit**: a tiny state cell with `get/set/update`.
- **Tree**: nested state where each path acts like a Unit.
- **Derived**: computed, read-only state.
- **Update Log**: patches produced by writes.

## What IO optimizes for

- **Deep updates, directly**: `state.user.name.set('Ada')` without reducers or action types.
- **Snapshot safety**: reads are frozen snapshots, so accidental mutation doesn’t leak.
- **Undo/redo & replay**: patches make time travel and syncing straightforward.
- **Opt-in extras**: `withBehaviors` adds `persist`, `devtools`, `schedule`, etc.
- **One integration contract**: `snapshot()` + `subscribe()` across adapters.

:::note
If you know Zustand: IO keeps the ergonomics, but makes deep state and patch-based updates first-class. The migration guide maps patterns side-by-side.
:::
