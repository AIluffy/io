## Install

<Steps>

1. Install the core package:

   ```bash
   npm install io-store
   ```

2. Add a framework adapter (optional):

   ```bash
   npm install io-react
   ```

</Steps>

:::note
If your project already uses a framework, install its adapter:
`io-react`, `io-vue`, or `io-svelte`.
:::

## Create state

```ts
import { io } from 'io-store';

const count = io(0);

count.get(); // read
count.set(1); // write
count.update((v) => v + 1); // update
```

:::tip
`get()` returns a frozen snapshot, so reads are safe to share and won’t be mutated by accident.
:::

## Use in your framework

<Tabs default="core">
  <TabItem label="Core" id="core">
    ```ts
    import { io, batch } from 'io-store';

    const store = io({ count: 0, user: { name: 'Ada' } });

    store.count.get();
    store.user.name.set('Grace');

    batch(() => {
      store.count.update((v) => v + 1);
      store.count.update((v) => v + 1);
    });

    const unsubscribe = store.count.subscribe((value) => {
      console.log('count changed', value);
    });

    // Later:
    unsubscribe();
    ```

  </TabItem>
  <TabItem label="React">
    ```tsx
    import { io } from 'io-store';
    import { useIO } from 'io-react';

    const count = io(0);

    export function Counter() {
      const value = useIO(count);
      return (
        <button onClick={() => count.update((v) => v + 1)}>{value}</button>
      );
    }
    ```

  </TabItem>
  <TabItem label="Vue">
    ```vue
    <script setup lang="ts">
    import { io } from 'io-store';
    import { ioRef, useIO } from 'io-vue';

    const count = io(0);
    const value = useIO(count);
    const model = ioRef(count);
    const inc = () => count.update((v) => v + 1);
    </script>

    <template>
      <button @click="inc">{{ value }}</button>
      <input v-model="model" type="number" />
    </template>
    ```

  </TabItem>
  <TabItem label="Svelte">
    ```svelte
    <script lang="ts">
      import { io } from 'io-store';
      import { toWritable } from 'io-svelte';

      const count = io(0);
      const countStore = toWritable(count);
      const inc = () => count.update((v) => v + 1);
    </script>

    <button on:click={inc}>{$countStore}</button>
    ```

  </TabItem>
</Tabs>

- Avoid putting the same object instance in an array twice. Create a new object for each item.
