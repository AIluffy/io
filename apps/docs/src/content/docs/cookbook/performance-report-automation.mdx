本页说明如何把性能数据自动产出成可发布页面，形成持续信任资产。

## 目标

- 每次主干构建都能生成最新性能页。
- 自动展示趋势、回归和运行环境。
- 能用于发布闸门（超预算告警）。

## 现有入口

- 基准页：[/cookbook/benchmark/](/cookbook/benchmark/)
- 详细页：通过 Benchmark 页面内链访问
- 生成命令：`npm exec nx -- run apps-docs:generate-bench`

## 推荐流水线

1. CI 执行 `@iostore/store:bench` 与 `@iostore/store:bench-gc`
2. 聚合脚本写入历史数据（JSON）
3. 生成 benchmark 文档页面
4. 构建 docs 并发布

## 发布闸门建议

- 设定关键场景预算阈值（如 mean 退化 > X%）。
- 预算超阈值时：
  1. 在报告页标红
  2. 在 CI 输出告警
  3. 发布流程要求显式风险确认

## 页面最小字段

- 运行环境（Node、平台、CPU、时间）
- 关键场景趋势图（至少 5 个）
- 相对上次变化（Top 回归 / Top 改进）
- 结论摘要与风险备注

## 常见误区

- 只看单次结果，不看趋势。
- 混用不同机器数据导致结论失真。
- 没有把性能告警接入发布流程。
