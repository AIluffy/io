## 是什么

Lynx 适配沿用 React 风格 Query 接口，并针对移动端高频交互保留取消与去重能力。

## 何时使用

- 你在 Lynx 页面中需要列表查询、提交与刷新。
- 你需要在弱网/快速切换场景降低竞态噪声。

## 核心 API

- [use-query](/api-reference/io-lynx/use-query/)
- [io-lynx-query-result](/api-reference/io-lynx/io-lynx-query-result/)
- [use-resource](/api-reference/io-lynx/use-resource/)

## 最小示例

```tsx
import { useQuery } from '@iostore/lynx';

const feed = useQuery({
  key: ['feed', category],
  queryFn: ({ signal }) =>
    fetch(`/api/feed?category=${category}`, { signal }).then((r) => r.json()),
  cancelOnUnmount: true,
});
```

## 常见误区

- 把取消视为异常告警，导致日志污染。
- 滑动切换分类时不重建 key，造成串页。
- 把重试次数设得过高，放大弱网压力。

## 实践建议

- 默认开启卸载取消，降低无效回写。
- 区分网络抖动与业务失败后再决定重试。
- 把分页和分类参数全部纳入 key。
