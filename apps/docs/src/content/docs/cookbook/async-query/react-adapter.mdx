## useQuery 与 useInfiniteQuery 如何选

| 场景 | 推荐 |
| --- | --- |
| 单资源/单页数据 | `useQuery` |
| 无限滚动、加载更多、聊天记录 | `useInfiniteQuery` |

## useInfiniteQuery 最小示例

```tsx
import { useInfiniteQuery } from '@iostore/react';

const feed = useInfiniteQuery({
  key: ['feed'],
  initialPageParam: 0,
  queryFn: ({ signal, pageParam }) =>
    fetch(`/api/feed?cursor=${pageParam}`, { signal }).then((r) => r.json()),
  getNextPageParam: (lastPage) => lastPage.nextCursor,
  cancelOnUnmount: true,
});

const rows = feed.data?.pages.flatMap((page) => page.items) ?? [];
```

## Suspense 场景

`useSuspenseInfiniteQuery` 与 `useSuspenseQuery` 一样，推荐搭配 ErrorBoundary 使用；
当查询未就绪时由 Suspense 兜底，页面不需要手写 `isLoading` 分支。

## 常见误区

- `queryFn` 忽略 `signal`，导致取消不生效。
- 误把 `AbortError` 当业务错误展示。
- 无限滚动场景继续用 `useQuery` 手工拼页，导致状态和取消逻辑分散。
