## 安装

```bash
npm i @iostore/store @iostore/vue vue
```

## 最小可复制示例

```ts
import { computed, ref } from 'vue';
import { useQuery } from '@iostore/vue';

type User = { id: string; name: string };

const tenantId = ref('acme');

const users = useQuery<User[]>({
  key: ['users', tenantId.value],
  queryFn: ({ signal }) =>
    fetch(`/api/users?tenant=${tenantId.value}`, { signal }).then((r) => r.json()),
  cancelOnDispose: true,
});

const rows = computed(() => users.data.value ?? []);
const isLoading = computed(() => users.state.value.isLoading);
```

## 状态分支渲染建议

- 首屏加载：使用 `isLoading`（或等价状态）。
- 后台刷新：使用 `isFetching`（或观察者 `fetchStatus`）。
- 错误态：直接展示可诊断信息，不要吞掉 `error`。

## 取消语义（AbortSignal）

- `queryFn` 必须透传 `signal` 到 `fetch` / 请求客户端。
- 把取消当作控制流，不当作业务失败弹窗。
- 页面快速切换场景启用取消（`cancelOnUnmount` / `cancelOnDispose` / `cancelOnUnsubscribe`）。

## 复制后需要改的 3 处

1. 把示例 key 改成业务域 key（例如 `users` -> `orders`）。
2. 把请求 URL 与返回类型改成项目真实接口。
3. 把重试、取消策略调成你的页面交互强度。
