## 安装

```bash
npm i @iostore/store @iostore/svelte svelte
```

## 最小可复制示例

```ts
// src/lib/users-query.ts
import { createQueryStore } from '@iostore/svelte';

type User = { id: string; name: string };

export const usersQuery = createQueryStore<User[]>({
  key: ['users', 'acme'],
  queryFn: ({ signal }) =>
    fetch('/api/users?tenant=acme', { signal }).then((r) => r.json()),
  cancelOnUnsubscribe: true,
});
```

```svelte
<script lang="ts">
  import { usersQuery } from '$lib/users-query';
</script>

{#if $usersQuery.isLoading}
  <p>Loading...</p>
{:else if $usersQuery.error}
  <p>{$usersQuery.error.message}</p>
{:else}
  <ul>
    {#each $usersQuery.data ?? [] as user}
      <li>{user.name}</li>
    {/each}
  </ul>
{/if}
```

## 状态分支渲染建议

- 首屏加载：使用 `isLoading`（或等价状态）。
- 后台刷新：使用 `isFetching`（或观察者 `fetchStatus`）。
- 错误态：直接展示可诊断信息，不要吞掉 `error`。

## 取消语义（AbortSignal）

- `queryFn` 必须透传 `signal` 到 `fetch` / 请求客户端。
- 把取消当作控制流，不当作业务失败弹窗。
- 页面快速切换场景启用取消（`cancelOnUnmount` / `cancelOnDispose` / `cancelOnUnsubscribe`）。

## 复制后需要改的 3 处

1. 把示例 key 改成业务域 key（例如 `users` -> `orders`）。
2. 把请求 URL 与返回类型改成项目真实接口。
3. 把重试、取消策略调成你的页面交互强度。
