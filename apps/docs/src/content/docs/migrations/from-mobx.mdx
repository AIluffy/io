本指南将常见 MobX 用法映射到 IO，并保持更新语义清晰可追踪。

## observable 类状态

MobX：

```ts
import { makeAutoObservable } from 'mobx';

class CounterStore {
  count = 0;

  constructor() {
    makeAutoObservable(this);
  }

  inc() {
    this.count += 1;
  }
}
```

IO：

```ts
import { io } from '@iostore/store';

const store = io({ count: 0 });
const inc = () => store.count.set((v) => v + 1);
```

## computed 派生值

MobX：

```ts
get double() {
  return this.count * 2;
}
```

IO：

```ts
import { derived } from '@iostore/store';

const double = derived([store.count], (count) => count * 2);
```

## action 批量更新

MobX 常用 `action` 或 `runInAction` 聚合更新。  
IO 中可使用 `commit`：

```ts
const profile = io({ name: 'Ada', age: 18 });

const updateProfile = (name: string, age: number) => {
  profile.commit((draft) => {
    draft.name = name;
    draft.age = age;
  });
};
```

## React 接入

MobX：

```tsx
import { observer } from 'mobx-react-lite';

const Counter = observer(() => <button onClick={() => store.inc()}>{store.count}</button>);
```

IO：

```tsx
import { useIO } from '@iostore/react';

function Counter() {
  const value = useIO(store.count);
  return <button onClick={inc}>{value}</button>;
}
```
