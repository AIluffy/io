本指南将常见 Valtio 用法转换为 IO 的 Unit 与快照模型。

## 创建状态

Valtio：

```ts
import { proxy } from 'valtio';

const state = proxy({ count: 0, user: { name: 'Ada' } });
```

IO：

```ts
import { io } from '@iostore/store';

const store = io({ count: 0, user: { name: 'Ada' } });
```

## 在 React 中读取

Valtio：

```tsx
import { useSnapshot } from 'valtio';

const snap = useSnapshot(state);
```

IO：

```tsx
import { useIO } from '@iostore/react';

const count = useIO(store.count);
const name = useIO(store.user.name);
```

## 修改状态

Valtio：

```ts
state.count += 1;
state.user.name = 'Grace';
```

IO：

```ts
store.count.set((v) => v + 1);
store.user.name.set('Grace');
```

## 批量更新

```ts
store.commit((draft) => {
  draft.count += 1;
  draft.user.name = 'Lin';
});
```
