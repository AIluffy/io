## 何时使用

当你需要该包提供的这项行为能力时使用此函数。

## 签名

```ts
<T>(input: IoView<T>, behaviors: IoBehavior<T>[]) => IoView<T>
```

## 参数

| Name | Type |
| --- | --- |
| input | `IoView<T>` |
| behaviors | `IoBehavior<T>[]` |

## 返回

`IoView<T>`

## 最小示例

```ts
import { withBehaviors } from '@iostore/store/behavior';

const result = withBehaviors(/* ...args */);
console.log(result);
```

## 常见误用

- 调用前请确认参数类型与可空性约束。
- 注意导入路径与运行环境（服务端/客户端）是否匹配。
