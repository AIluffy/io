## 签名

```ts
devtools<T>(options: {
  target: unknown;
  create: (target: unknown, options?: unknown) => unknown;
  options?: unknown;
  key?: string;
}): IoBehavior<T>
```

## 说明

- `create` 通常使用 `io-devtools` 的 `createIoDevtools`。
- 实例会挂载到 `view.extensions[key]`（默认 `devtools`）。
