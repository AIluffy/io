## 何时使用

当你需要共享常量或运行时能力时使用此导出值。

## 签名

```ts
any
```

## 最小示例

```ts
import { DEFAULT_GC_TIME } from '@iostore/store/query';

console.log(DEFAULT_GC_TIME);
```

## 常见误用

- 除非文档明确说明，否则将导出值视为只读。
- 避免跨模块直接修改共享引用。
