## 何时使用

当你需要复用类型结构时使用此类型别名。

## 签名

```ts
IoQueryClientOptions
```

## 属性

| Name | Type |
| --- | --- |
| defaultStaleTime | `number` |
| defaultGcTime | `number` |
| defaultRetry | `IoRetryValue` |
| defaultRetryDelay | `IoRetryDelayValue` |
| hashKey | `(key: IoQueryKey) => string` |

## 最小示例

```ts
import type { IoQueryClientOptions } from '@iostore/query';

let value!: IoQueryClientOptions;
console.log(value);
```

## 常见误用

- 避免在用户文档中展开过于复杂的类型细节。
- 调整类型别名时注意下游兼容性。
