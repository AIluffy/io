## 何时使用

当你需要复用类型结构时使用此类型别名。

## 签名

```ts
IoResourceOptions<TData>
```

## 属性

| Name | Type |
| --- | --- |
| key | `unknown` |
| queryFn | `IoQueryFn<TData>` |
| client | `IoQueryClient` |
| staleTime | `number` |
| gcTime | `number` |
| retry | `IoRetryValue` |
| retryDelay | `IoRetryDelayValue` |
| action | `string` |
| meta | `Record<string, unknown>` |

## 最小示例

```ts
import type { IoResourceOptions } from '@iostore/query';

let value!: IoResourceOptions;
console.log(value);
```

## 常见误用

- 避免在用户文档中展开过于复杂的类型细节。
- 调整类型别名时注意下游兼容性。
