## 何时使用

当你需要该包提供的这项行为能力时使用此函数。

## 签名

```ts
<TData>(resource: IoResource<TData>, options?: IoUseResourceOptions) => IoQueryResult<TData>
```

## 参数

| Name | Type |
| --- | --- |
| resource | `IoResource<TData>` |
| options | `IoUseResourceOptions` |

## 返回

`IoQueryResult<TData>`

## 最小示例

```ts
import { useResource } from '@iostore/react';

const result = useResource(/* ...args */);
console.log(result);
```

## 常见误用

- 调用前请确认参数类型与可空性约束。
- 注意导入路径与运行环境（服务端/客户端）是否匹配。
