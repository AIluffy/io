## 何时使用

当你需要复用类型结构时使用此类型别名。

## 签名

```ts
IoDevtools
```

## 属性

| Name | Type |
| --- | --- |
| getState | `() => IoDevtoolsState` |
| subscribe | `(listener: (event: IoDevtoolsEvent) => void) => Unsubscribe` |
| setEnabled | `(enabled: boolean) => void` |
| pause | `() => void` |
| resume | `() => void` |
| destroy | `() => void` |
| clear | `() => void` |
| timeTravel | `{ undo: () => boolean; redo: () => boolean; goTo: (index: number) => boolean; }` |
| export | `{ json: () => string; reduxDevToolsImport: () => ReduxDevToolsImportState; }` |
| connectReduxDevToolsExtension | `(options?: { window?: unknown; name?: string; }) => IoDevtoolsBridge \| null` |

## 最小示例

```ts
import type { IoDevtools } from '@iostore/devtools';

let value!: IoDevtools;
console.log(value);
```

## 常见误用

- 避免在用户文档中展开过于复杂的类型细节。
- 调整类型别名时注意下游兼容性。
