## 何时使用

当你需要该包提供的这项行为能力时使用此函数。

## 签名

```ts
<TData, TError = Error, TPageParam = unknown, TSelected = InfiniteData<TData, TPageParam>>(options: UseInfiniteQueryOptions<TData, TError, TPageParam, TSelected>, suspenseOptions?: SuspenseCompatOptions) => UseSuspenseInfiniteQueryResult<TData, TError, TPageParam, TSelected>
```

## 参数

| Name | Type |
| --- | --- |
| options | `UseInfiniteQueryOptions<TData, TError, TPageParam, TSelected>` |
| suspenseOptions | `SuspenseCompatOptions` |

## 返回

`UseSuspenseInfiniteQueryResult<TData, TError, TPageParam, TSelected>`

## 最小示例

```ts
import { useSuspenseInfiniteQuery } from '@iostore/react';

const result = useSuspenseInfiniteQuery(/* ...args */);
console.log(result);
```

## 常见误用

- 调用前请确认参数类型与可空性约束。
- 注意导入路径与运行环境（服务端/客户端）是否匹配。
