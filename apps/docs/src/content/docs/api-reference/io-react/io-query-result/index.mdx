## 何时使用

当你需要标注 `useQuery` 返回值类型时使用。

## 签名

```ts
UseQueryResult<TData, TError = Error>
```

## 属性

| Name | Type |
| --- | --- |
| status | `IoDataStatus` |
| fetchStatus | `IoFetchStatus` |
| data | `TData \| undefined` |
| error | `TError \| null` |
| dataUpdatedAt | `number` |
| errorUpdatedAt | `number` |
| failureCount | `number` |
| isPending | `boolean` |
| isSuccess | `boolean` |
| isError | `boolean` |
| isFetching | `boolean` |
| isLoading | `boolean` |
| isRefetching | `boolean` |
| refetch | `() => Promise<TData>` |
| query | `IoQuery<TData, TError>` |

## 最小示例

```ts
import type { UseQueryResult } from '@iostore/react';

let value!: UseQueryResult<number>;
console.log(value);
```
