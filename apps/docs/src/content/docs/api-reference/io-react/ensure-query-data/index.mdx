## 签名

```ts
<TData, TError = Error>(options: { input: ResolveQueryInput<TData, TError>; client?: IoQueryClient; }) => Promise<TData>
```

## 参数

| Name | Type |
| --- | --- |
| options | `{ input: ResolveQueryInput<TData, TError>; client?: IoQueryClient; }` |

## 返回

`Promise<TData>`

## 最小示例

```ts
import { ensureQueryData } from '@iostore/react/rsc';

const result = ensureQueryData(/* ...args */);
console.log(result);
```
