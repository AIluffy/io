## 何时使用

当你需要该包提供的这项行为能力时使用此函数。

## 签名

```ts
<TData, TError = Error, TSelected = TData>(options: IoUseQueryOptions<TData, TError, TSelected>) => IoSolidQueryResult<TData, TError, TSelected>
```

## 参数

| Name | Type |
| --- | --- |
| options | `IoUseQueryOptions<TData, TError, TSelected>` |

## 返回

`IoSolidQueryResult<TData, TError, TSelected>`

## 最小示例

```ts
import { useQuery } from '@iostore/solid';

const result = useQuery(/* ...args */);
console.log(result);
```

## 常见误用

- 调用前请确认参数类型与可空性约束。
- 注意导入路径与运行环境（服务端/客户端）是否匹配。
