## 何时使用

当你需要该包提供的这项行为能力时使用此函数。

## 签名

```ts
<TSource, TSelected>(source: IoSource<TSource>, selector: (value: TSource) => TSelected, options?: IoSelectorOptions<TSelected>) => Accessor<TSelected>
```

## 参数

| Name | Type |
| --- | --- |
| source | `IoSource<TSource>` |
| selector | `(value: TSource) => TSelected` |
| options | `IoSelectorOptions<TSelected>` |

## 返回

`Accessor<TSelected>`

## 最小示例

```ts
import { useIOSelector } from '@iostore/solid';

const result = useIOSelector(/* ...args */);
console.log(result);
```

## 常见误用

- 调用前请确认参数类型与可空性约束。
- 注意导入路径与运行环境（服务端/客户端）是否匹配。
