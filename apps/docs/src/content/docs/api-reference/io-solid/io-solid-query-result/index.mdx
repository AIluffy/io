## 何时使用

当你需要复用类型结构时使用此类型别名。

## 签名

```ts
IoSolidQueryResult<TData>
```

## 属性

| Name | Type |
| --- | --- |
| state | `Accessor<IoQueryState<TData>>` |
| data | `Accessor<TData>` |
| error | `Accessor<unknown>` |
| fetch | `(options?: IoResourceRequestOptions) => Promise<TData>` |
| refetch | `() => Promise<TData>` |
| prefetch | `(options?: IoResourceRequestOptions) => Promise<void>` |
| invalidate | `(options?: { action?: string; meta?: Record<string, unknown>; }) => number` |
| cancel | `() => number` |

## 最小示例

```ts
import type { IoSolidQueryResult } from '@iostore/solid';

let value!: IoSolidQueryResult;
console.log(value);
```

## 常见误用

- 避免在用户文档中展开过于复杂的类型细节。
- 调整类型别名时注意下游兼容性。
