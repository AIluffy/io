## 何时使用

当你需要复用类型结构时使用此类型别名。

## 签名

```ts
IoHistory
```

## 属性

| Name | Type |
| --- | --- |
| undo | `() => void` |
| undoGroup | `() => void` |
| redo | `() => void` |
| redoGroup | `() => void` |
| checkpoint | `() => void` |
| clear | `() => void` |
| destroy | `() => void` |
| canUndo | `boolean` |
| canRedo | `boolean` |
| length | `number` |
| cursor | `number` |

## 最小示例

```ts
import type { IoHistory } from '@iostore/store/patches';

let value!: IoHistory;
console.log(value);
```

## 语义说明

- `undo/redo`：按单条 update 前进或回退。
- `undoGroup/redoGroup`：按 `groupBy` 聚合后的“组”前进或回退。
- `checkpoint`：强制切分下一个记录组。
- `cursor`：当前历史游标（`-1` 表示位于历史起点）。

## 常见误用

- 在没有配置 `groupBy` 的情况下期待 `undoGroup` 能批量回退。
- 在 `destroy` 后继续复用同一个 history 实例。
