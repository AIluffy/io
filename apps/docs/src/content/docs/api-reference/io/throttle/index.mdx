---
title: "throttle"
description: "行为 API：限制订阅通知频率。"
---

## 何时使用

- 高频更新，但只需要固定节奏下发通知。
- 减少 UI 因连续写入造成的抖动。

## 签名

```ts
<T>(waitMs: number, options?: ThrottleBehaviorOptions) => IoBehavior<T>
```

## 参数

| Name | Type |
| --- | --- |
| waitMs | `number` |
| options | `ThrottleBehaviorOptions` |

## 返回

`IoBehavior<T>`

## 最小示例

```ts
import { io } from '@iostore/store';
import { throttle, withBehaviors } from '@iostore/store/behavior';

const count = io(0);
const view = withBehaviors(count, [throttle(50)]);
```

## 常见误用

- 期望每次更新都触发回调，却使用了 `throttle` 导致中间值被采样丢弃。
- 把节流窗口设得过短，几乎没有降低通知频率。
