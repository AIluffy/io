## 何时使用

当你需要该包提供的这项行为能力时使用此函数。

## 签名

```ts
<T>(unit: IoUnit<T>, options?: IoSvelteOptions) => Writable<T>
```

## 参数

| Name | Type |
| --- | --- |
| unit | `IoUnit<T>` |
| options | `IoSvelteOptions` |

## 返回

`Writable<T>`

## 最小示例

```ts
import { toWritable } from '@iostore/svelte';

const result = toWritable(/* ...args */);
console.log(result);
```

## 常见误用

- 调用前请确认参数类型与可空性约束。
- 注意导入路径与运行环境（服务端/客户端）是否匹配。
