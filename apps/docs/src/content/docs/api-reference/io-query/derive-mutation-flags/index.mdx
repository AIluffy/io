## 何时使用

当你直接消费 `IoMutationState`，并需要便捷状态标记时使用。

## 签名

```ts
function deriveMutationFlags<TData, TError>(
  state: IoMutationState<TData, TError>,
): IoMutationDerivedFlags;
```

## 最小示例

```ts
const flags = deriveMutationFlags(mutation.snapshot());
if (flags.isPending) {
  console.log('提交中...');
}
```

## 常见误用

- 从旧快照计算 flags，导致 UI 状态滞后。
