title: "IoDataStatus"
description: "Query 状态中数据轴的状态联合类型。"
---

## 何时使用

用于描述 Query 状态机的数据轴阶段。

## 签名

```ts
type IoDataStatus = 'pending' | 'success' | 'error';
```

## 最小示例

```ts
function isReady(status: IoDataStatus): boolean {
  return status === 'success';
}
```

## 常见误用

- 把 `pending` 当作 `fetching`；请求进行中应看 `IoFetchStatus`。
