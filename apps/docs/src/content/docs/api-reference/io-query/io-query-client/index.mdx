## 一句话定位

`IoQueryClient` 是 Query 运行时入口：负责定义查询、观察状态、缓存读写、失效、重取、脱水/注水。

## Infinite Query 相关能力

除常规 Query 方法外，`IoQueryClient` 还提供：

- `defineInfiniteQuery(definition)`
- `observeInfiniteQuery(options)`
- `prefetchInfiniteQuery(definition, pages?)`
- `getInfiniteQuery(key)`
- `getInfiniteQueryData(key)`
- `setInfiniteQueryData(key, updater)`
- `getInfiniteQueryState(key)`

## 示例

```ts
const feed = client.defineInfiniteQuery({
  key: ['feed'],
  initialPageParam: 0,
  queryFn: ({ signal, pageParam }) => fetch(`/api/feed?cursor=${pageParam}`, { signal }).then((r) => r.json()),
  getNextPageParam: (lastPage) => lastPage.nextCursor,
});

await feed.fetchNextPage();
client.invalidateQueries({ key: ['feed'], exact: true });
```
