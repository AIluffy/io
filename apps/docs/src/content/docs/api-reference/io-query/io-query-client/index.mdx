## 何时使用

当你需要复用类型结构时使用此类型别名。

## 签名

```ts
IoQueryClient
```

## 最小示例

```ts
import type { IoQueryClient } from '@iostore/store/query';

let value!: IoQueryClient;
console.log(value);
```

## 常见误用

- 避免在用户文档中展开过于复杂的类型细节。
- 调整类型别名时注意下游兼容性。
