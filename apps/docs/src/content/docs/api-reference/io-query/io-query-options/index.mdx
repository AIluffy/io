## 何时使用

向 `createQuery` 或 `client.query` 传入 `IoQueryOptions`，用于配置 key、请求函数、缓存时序、重试与回调。

## 签名

```ts
type IoQueryOptions<TData = unknown, TError = Error> = {
  key: IoQueryKey;
  queryFn: (context: { signal: AbortSignal }) => Promise<TData>;
  staleTime?: number;
  gcTime?: number;
  retry?: number;
  retryDelay?: (attempt: number) => number;
  autoFetch?: boolean;
  placeholderData?: TData | (() => TData);
  onSuccess?: (data: TData) => void;
  onError?: (error: TError) => void;
  onSettled?: (data: TData | undefined, error: TError | null) => void;
};
```

## 属性

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `key` | `IoQueryKey` | Yes | — | 缓存标识，需可序列化且稳定。 |
| `queryFn` | `(context: { signal: AbortSignal }) => Promise<TData>` | Yes | — | 异步请求函数，必须透传 `signal`。 |
| `staleTime` | `number` | No | `0` | 新鲜窗口（毫秒），`0` 表示始终过期。 |
| `gcTime` | `number` | No | `300000` | 无订阅后进入 GC 的延迟（毫秒）。 |
| `retry` | `number` | No | `0` | 非取消错误的最大重试次数。 |
| `retryDelay` | `(attempt: number) => number` | No | `min(1000 * 2^attempt, 30000)` | 下次重试前延迟。 |
| `autoFetch` | `boolean` | No | `false` | 创建后是否立即抓取。 |
| `placeholderData` | `TData \| (() => TData)` | No | `undefined` | 首次 pending 阶段占位数据。 |
| `onSuccess` | `(data: TData) => void` | No | `undefined` | 成功后回调。 |
| `onError` | `(error: TError) => void` | No | `undefined` | 失败后回调。 |
| `onSettled` | `(data: TData \| undefined, error: TError \| null) => void` | No | `undefined` | 成功/失败都会触发。 |

## 最小示例

```ts
const query = client.query({
  key: ['todos', { status: 'active' }],
  queryFn: ({ signal }) =>
    fetch('/api/todos?status=active', { signal }).then((r) => r.json()),
  staleTime: 5_000,
  gcTime: 10 * 60_000,
  retry: 2,
  autoFetch: true,
});
```

## 常见误用

- key 中漏掉请求参数，导致缓存冲突。
- `queryFn` 不透传 `signal`，取消无法中断网络请求。
- 误以为默认会重试；默认 `retry` 为 `0`。
