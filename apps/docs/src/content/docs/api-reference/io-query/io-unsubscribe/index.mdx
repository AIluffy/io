## 何时使用

用于表示各类 `subscribe(...)` 返回的取消订阅函数。

## 签名

```ts
type IoUnsubscribe = () => void;
```

## 最小示例

```ts
const unsub: IoUnsubscribe = query.subscribe(() => {
  console.log(query.snapshot());
});
unsub();
```

## 常见误用

- 在长生命周期副作用中忘记调用取消订阅。
