## 何时使用

用于调试 Query 缓存身份、或做稳定 key 比较时使用 `hashKey`。

## 签名

```ts
function hashKey(key: IoQueryKey): string;
```

## 最小示例

```ts
const hash = hashKey(['users', { page: 1 }]);
console.log(hash);
```

## 常见误用

- 传入不可序列化值（function/symbol/循环引用）会直接抛错。
