---
title: "IoQueryCacheEvent"
description: "IoQueryClient.subscribe 发出的缓存事件负载类型。"
---

## 何时使用

当你需要监听 Query 缓存新增、更新、移除事件时使用。

## 签名

```ts
type IoQueryCacheEvent = {
  type: 'query-added' | 'query-updated' | 'query-removed';
  query: IoQuery<unknown, unknown>;
};
```

## 最小示例

```ts
const unsub = client.subscribe((event) => {
  console.log(event.type, event.query.keyHash);
});
```

## 常见误用

- 不做过滤就对每次 `query-updated` 执行重逻辑。
