---
title: "IoFetchStatus"
description: "Query 状态中请求轴的状态联合类型。"
---

## 何时使用

用于描述 Query 请求是否正在进行中。

## 签名

```ts
type IoFetchStatus = 'idle' | 'fetching';
```

## 最小示例

```ts
const isFetching = state.fetchStatus === 'fetching';
```

## 常见误用

- 只看 `fetchStatus` 不看 `status`，会混淆首次加载与后台刷新。
