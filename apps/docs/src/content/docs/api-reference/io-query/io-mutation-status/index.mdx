## 何时使用

用于表示 mutation 生命周期阶段。

## 签名

```ts
type IoMutationStatus = 'idle' | 'pending' | 'success' | 'error';
```

## 最小示例

```ts
if (mutation.snapshot().status === 'pending') {
  showSpinner();
}
```

## 常见误用

- 新一轮 mutation 开始后仍把旧 `success` 当作当前状态。
