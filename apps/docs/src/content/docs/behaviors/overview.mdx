行为扩展（Behavior）用于在不改变核心 API 的前提下增加能力，例如持久化、调度、节流、防抖、副作用和 DevTools。

## 基础用法

```ts
import { io } from '@iostore/store';
import {
  persist,
  schedule,
  throttle,
  effect,
  withBehaviors,
} from '@iostore/store/behavior';

const count = io(0);
const view = withBehaviors(count, [
  persist({ key: 'count' }),
  schedule('microtask'),
  throttle(50),
  effect((value) => console.log(value)),
]);

view.subscribe((value) => {
  console.log(value);
});
```

## IoView 接口

`withBehaviors` 会把原始节点适配成 `IoView`：

- `get()` / `set()`
- `subscribe()` / `snapshot()`
- `extensions`：扩展实例容器
- `destroy()`：统一清理

## 组合策略

- 先接入 `persist`，再接入 `schedule` 或 `devtools`。
- 高频场景建议先 `throttle/debounce`，再接 `effect`。
- 行为顺序决定包装顺序，按依赖关系排列。
