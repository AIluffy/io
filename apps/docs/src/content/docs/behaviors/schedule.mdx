Schedule 用于合并或延迟订阅通知，降低渲染抖动。

## 基础用法

```ts
import { io } from 'io-store';
import { schedule, withBehaviors } from 'io-store/behavior';

const count = io(0);
const view = withBehaviors(count, [schedule('microtask')]);

view.subscribe((value) => {
  console.log('notified', value);
});
```

## 可选策略

- `sync`：立即触发
- `microtask`：同一事件循环合并
- `animationFrame`：下一帧前触发（若可用）

## 适用场景

- UI 渲染抖动较大时
- 写入频繁，但允许延迟到下一帧
