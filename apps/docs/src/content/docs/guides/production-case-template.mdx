## B. 10 分钟选型决策表

给每项打分（0-2），总分 >= 8 通常优先推荐 IO。

| 问题 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 深层状态复杂度 | 简单扁平 | 中等 | 深层复杂 |
| 回放/撤销/审计需求 | 无 | 偶尔 | 强需求 |
| 多框架协作 | 单框架 | 2 个框架 | >= 3 个框架 |
| 迁移窗口 | 极短 | 可分阶段 | 可系统迁移 |
| 性能瓶颈来源 | 非状态层 | 部分相关 | 状态更新主导 |

## C. 最小必填发布数据

- 变更范围（模块数/文件数）
- 回归矩阵执行结果（P0/P1）
- 线上观测窗口（至少 24h）
- 错误分级记录（SEV 统计）
