`batch()` 会把多次写入合并成一次通知，减少重复渲染与 patch 噪音。

## 基础用法

```ts
import { batch, io } from 'io-store';

const store = io({ count: 0, user: { name: 'Ada' } });

batch(() => {
  store.count.set((v) => v + 1);
  store.user.name.set('Lin');
});
```

## 作用范围

- 合并 `subscribe` 的值通知。
- 合并 `subscribeUpdate` 的 patch 更新（内部会 merge）。

## 何时使用

- 同一逻辑动作涉及多处写入。
- 需要减少 UI 抖动或订阅触发次数。
