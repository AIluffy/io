IO 支持通过 `link()` 显式复用已有 IO 节点，避免误把节点当作普通对象展开。

## 使用方式

```ts
import { io, link } from '@iostore/store';

const count = io(0);
const store = io({ count: link(count) });

store.count === count; // true
```

## 为什么必须显式

- IO 节点是带方法的对象，隐式展开会把方法当作普通字段，导致快照/克隆失败。
- 结构更清晰：`link()` 表示“引用节点”，否则就是“普通值”。
- 避免不小心把外部节点混进 Tree，造成循环或不可预期的更新路径。

## 语义

- **保持引用身份**：`store.count === count`。
- **冒泡更新**：对子节点的更新会向父树冒泡，patch 路径自动前缀。
- **快照读取**：`store.snapshot()` 读取到被引用节点的快照值。
- **数组复用规则**：同一节点在数组里出现多次时，更新会冒泡到每个索引位置（生成多条 patch 路径）。

## 限制与注意事项

- **必须显式使用 `link()`**。直接 `io({ count })` 会被当作普通对象展开并在克隆/快照阶段失败。
- **请避免循环引用**（例如把父节点重新挂回子节点）。
- **跨树引用** 会被视作外部节点，DevTools 仅记录根路径，不展开子路径。
