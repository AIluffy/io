OIN 是一个 TypeScript 状态库：以少量数据结构原语（Unit / Scope / ArrayUnit / Tree）为核心，并用显式的变更日志格式（Patch/Update）把“写入”变成可追踪、可合并、可回放的序列。本页把对外 API 与内部模块一一对齐，并说明关键设计原因。

## 模块划分

### 数据模型层

- `Unit<T>`：函数式单元：`unit()` 读取，`unit(next)` 写入。
- `Scope<T>`：对象的每个 key 是 `OinUnit`，支持 `commit()` 将多 key 更新合并为一次更新。
- `ArrayUnit<T>`：数组容器，元素为 Unit，提供 `splice` / `sort` 等数组操作。
- `TreeNode<T>`：由 `oin()` 构建的深层节点，用于路径级变更与回放（`oinTree()` / `oinDeep()` 已弃用）。

源码映射（核心包）：`unit.ts`、`scope.ts`、`array-unit.ts`、`oin-tree.ts`、`types.ts`。

### 变更与可观测层

- Patch 是最小变更记录（`set` / `splice` / `sort`），携带 `path`。
- Update 是 Patch 列表与元信息，可合并、可逆、可应用、可回放。
- `batch()` 用于合并通知与合并 updates，提升性能与可预测性。
- 调试钩子提供统一的变更观察与失败上报。

源码映射：`updates.ts`、`batch.ts`、`debug.ts`。

### 派生与响应式内核

- `formula(deps, compute)`：显式依赖列表，订阅驱动，避免隐式依赖与泄漏。
- `derive(node, selector)`：selector 驱动，通过内部 reactive core 跟踪读取。
- reactive core：`state` / `computed` / `effect` / `untrack`，用于依赖收集与调度。

源码映射：`formula.ts`、`derive.ts`、`signals.ts`。

### Snapshot 语义

所有读取（返回对象/数组时）都会给出冻结快照：避免原地修改，并保证“同 revision 读到的值”具备引用稳定性。

源码映射：`snapshot.ts`。

## 技术栈选型依据

- TypeScript 优先：类型即契约，提升可维护性与重构安全性。
- 显式 Patch/Update：支持 time-travel、replay，以及将来外部同步/协作的可能。
- 冻结快照：让“错误的可变写入”快速暴露，形成只读默认的使用习惯。
- Monorepo 工具链：Nx 统一 build/test/typecheck；Vite/Vitest 提升开发效率。
- 文档站：Astro + Starlight 结构化导航，Pagefind 提供全文搜索。
