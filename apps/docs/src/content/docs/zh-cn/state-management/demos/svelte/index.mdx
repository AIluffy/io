当前文档站未启用 Svelte 集成（未安装 `@astrojs/svelte`），本页仅提供最小骨架与注意事项。

## 最小骨架

安装依赖：

```bash
pnpm -C apps/docs add @astrojs/svelte svelte
```

在 `astro.config.mjs` 中启用 Svelte integration，然后用 island 方式渲染：

```astro
---
import Counter from '../components/Counter.svelte';
---

<Counter client:load />
```

## 注意事项

- 使用 `subscribe` 时注意在组件卸载时释放订阅。
- SSR 输出应保持纯静态，交互交给 islands。
