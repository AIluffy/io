当前文档站未启用 Solid 集成（未安装 `@astrojs/solid`），本页仅提供最小骨架与注意事项。

## 最小骨架

安装依赖：

```bash
pnpm -C apps/docs add @astrojs/solid solid-js
```

在 `astro.config.mjs` 中启用 Solid integration，然后用 island 方式渲染：

```astro
---
import Counter from '../components/Counter.tsx';
---

<Counter client:load />
```

## 注意事项

- 把 store 与 effect 限定在 island 生命周期内。
- SSR 输出应保持纯静态，交互交给 islands。
