IO 的核心 API 与框架无关，直接使用 `snapshot()` + `subscribe()` 即可。

## 基础示例

```ts
import { io } from 'io-store';

const store = io({ count: 0 });

const stop = store.count.subscribe((value) => {
  console.log('render', value);
});

store.count.set(1);
stop();
```

## 订阅更新日志

```ts
const stopUpdate = store.subscribeUpdate((update) => {
  console.log(update.patches);
});
```

## 手动调度

如果需要合并通知，请使用 `batch()` 或行为扩展 `schedule()`：

```ts
import { batch } from 'io-store';

batch(() => {
  store.count.set(1);
  store.count.set(2);
});
```
