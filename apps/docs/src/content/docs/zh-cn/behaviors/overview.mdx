行为扩展会包装视图的 `get/set/subscribe`，不改变原始 Unit 或 Tree。这样就能方便地添加持久化、调度或工具能力。

```ts
import { io } from 'io-store';
import { persist, schedule, withBehaviors } from 'io-store/behavior';

const count = io(0);

const view = withBehaviors(count, [
  schedule('microtask'),
  persist({ key: 'count' }),
]);

view.subscribe((v) => console.log(v));
view(1);
```

## 常见行为

- **Persist**：写入时同步到存储。
- **Schedule**：控制订阅触发时机。
- **DevTools**：附加调试工具实例。
