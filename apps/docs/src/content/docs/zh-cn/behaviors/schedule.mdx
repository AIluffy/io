## 合并通知

通过 schedule 行为延迟订阅通知，降低渲染抖动。

```ts
import { oin } from '@oin/store';
import { schedule, withBehaviors } from '@oin/store/behavior';

const count = oin(0);
const view = withBehaviors(count, [schedule('microtask')]);

view.subscribe((value) => {
  console.log('notified', value);
});
```

## 可选参数

- `sync`：立即触发
- `microtask`：同一事件循环合并
- `animationFrame`：下一帧前触发（若可用）
