## 签名

```ts
devtools<T>(options: {
  target: unknown;
  create: (target: unknown, options?: unknown) => unknown;
  options?: unknown;
  key?: string;
}): OinBehavior<T>
```

## 说明

- `create` 通常使用 `@oin/devtools` 的 `createOinDevtools`。
- 实例会挂载到 `view.extensions[key]`（默认 `devtools`）。
