## 签名

```ts
OinTreeArrayUnit<T, MaxDepth>
```

## 说明

- 用于深层数组（MaxDepth > 1）；`OinArrayUnit` 是浅层别名。
- `commit` 通过 draft diff 更新数组内容。

## 错误
