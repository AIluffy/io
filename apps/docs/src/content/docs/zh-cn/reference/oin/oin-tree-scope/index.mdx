## 签名

```ts
OinTreeScope<T, MaxDepth>
```

## 说明

- 用于深层对象 Scope（MaxDepth > 1）；`OinScope` 是浅层别名。
- `commit` 不允许新增未知 key，以保持结构稳定。

## 属性

| Name | Type |
| --- | --- |
| commit | `(fn: (draft: T) => void) => void` |
| snapshot | `() => T` |
| subscribe | `(fn: (v: T) => void) => OinUnsubscribe` |
| subscribeUpdate | `(fn: (u: OinUpdate) => void) => OinUnsubscribe` |

## 错误

- 本库未定义标准化错误码。
- 变更失败可通过 `onError(listener)` 上报（operation、path、value）。
