---
title: "persist"
description: "行为：持久化适配"
---

## 签名

```ts
persist<T>(options: {
  key: string;
  storage?: { getItem(key: string): string | null; setItem(key: string, value: string): void };
  serialize?: (value: unknown) => string;
  deserialize?: (raw: string) => unknown;
}): OinBehavior<T>
```

## 说明

- 默认使用 `localStorage`（若存在）。
- 初始化时若有存储值，会通过 `set` 应用。
