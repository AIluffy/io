## 签名

```ts
<T>(initial: T, options?: { silent?: boolean; shallow?: boolean }) => OinResult<T>
```

`oin()` 对 object / array 默认 deep，等价旧 `oinTree()` / `oinDeep()`；如需浅层对象/数组行为使用 `oin(value, { shallow: true })`。

## 参数

| Name | Type |
| --- | --- |
| initial | `T` |

## 返回

`OinResult<T>`

## 错误

- 本库未定义标准化错误码。
- 变更失败可通过 `onError(listener)` 上报（operation、path、value）。

## 鉴权

- 不适用。OIN 是本地 TypeScript/JavaScript 库，不包含鉴权机制。
