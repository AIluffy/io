## 签名

```ts
IoTreeArrayUnit<T, MaxDepth>
```

## 说明

- 用于深层数组（MaxDepth > 1）；`IoArrayUnit` 是浅层别名。
- `commit` 通过 draft diff 更新数组内容。
- `set()` 会替换整个数组，并在数组路径上发出 `set` patch。

## 错误
