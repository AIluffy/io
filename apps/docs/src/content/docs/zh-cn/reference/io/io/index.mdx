## 签名

```ts
<T>(target: T, options: { shallow: true }) => IoNode<T>
<T>(target: T, options?: { shallow?: false }) => IoResult<T>
```

## 参数

| Name | Type |
| --- | --- |
| target | `T` |
| options | `{ shallow: true }` or `{ shallow?: false }` |

## 返回

`IoNode<T>`

## 说明

- `shallow: true` 仅保留第一层（内部仍使用同一 Tree 引擎）。
- 浅层模式下 `commit` 不允许新增未知 key，以保持结构稳定。
- 深度模式只能跟踪纯对象和数组，传入非纯对象会抛出 `TypeError`。需要深度追踪时请把复杂值包裹在浅层节点中。

## 错误

- 本库未定义标准化错误码。
- 变更失败可通过 `onError(listener)` 上报（operation、path、value）。
