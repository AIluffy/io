## 第一个状态

```ts
import { oin } from '@oin/store';

const count = oin(0);

count();          // 读取
count(1);         // 写入
count((v) => v + 1);
```

## 默认深层

`oin()` 对 object / array 默认进行 deep 处理，因此 `user.profile.name(...)` 这种深层属性级 Unit 不需要额外切换 API。

```ts
import { oin } from '@oin/store';

const user = oin({ profile: { name: 'Ada' } });

user.profile.name();        // "Ada"
user.profile.name('Grace'); // 写入路径 ["profile","name"]
```

如需“仅第一层变成 unit”的旧行为，使用 `oinShallow()`；`oinTree()` / `oinDeep()` 仍可用但已弃用。
