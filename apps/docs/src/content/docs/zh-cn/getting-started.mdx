## 安装

<Steps>

    ```bash
    npm install @oin/store
    ```

2.  安装框架适配器 (可选):

    ```bash
    npm install @oin/react
    ```

## 第一个状态

```ts
import { oin } from '@oin/store';

const count = oin(0);

count();          // 读取
count(1);         // 写入
count((v) => v + 1);
```

## 深层树模式

`oin()` 对对象默认是浅层 Scope（只有第一层 key 会变成 unit）。当你希望 `user.profile.name(...)` 这种深层属性级 Unit 时，使用 `oinTree()` / `oinDeep()`。

```ts
import { oinDeep } from '@oin/store';

const user = oinDeep({ profile: { name: 'Ada' } });

user.profile.name();        // "Ada"
user.profile.name('Grace'); // 写入路径 ["profile","name"]
```
