## 默认冻结

任何对象/数组读取都会返回冻结快照，避免误修改。

```ts
import { io } from 'io-store';

const state = io({ items: ['a', 'b'] });
const snapshot = state.snapshot();

Object.isFrozen(snapshot); // true
```

## snapshot API

```ts
const count = io(0);

count.snapshot();
```

同一版本内快照具有稳定引用，适合缓存与渲染优化。

## `get()` vs `snapshot()`

- 需要参与依赖追踪（例如在 `derived()` 中）时用 `get()`。
- 只想拿值、不希望被追踪时用 `snapshot()`。
