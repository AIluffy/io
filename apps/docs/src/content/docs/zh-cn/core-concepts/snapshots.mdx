## 默认冻结

任何对象/数组读取都会返回冻结快照，避免误修改。

```ts
import { oin } from '@oin/store';

const state = oin({ items: ['a', 'b'] });
const snapshot = state.snapshot();

Object.isFrozen(snapshot); // true
```

## snapshot API

```ts
const count = oin(0);

count.snapshot();
```

同一版本内快照具有稳定引用，适合缓存与渲染优化。
