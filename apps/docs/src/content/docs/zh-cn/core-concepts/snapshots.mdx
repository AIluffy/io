IO 的读取默认返回**冻结快照**，避免意外修改穿透到状态内部。

## snapshot 与 get

- `snapshot()`：返回冻结快照，适合序列化与跨层传递。
- `get()`：读取值，并用于派生值的依赖追踪。

```ts
const store = io({ count: 0 });

const snap = store.snapshot();
const value = store.count.get();
```

## 为什么冻结

冻结快照能保证：

- UI 读取后不会误改状态。
- Snapshot 可安全缓存与复用。
- Debug/Replay 时可以对比前后差异。

## 快照缓存

树节点会缓存快照，仅在路径变脏时重建局部数据，从而避免全量复制。

## 建议

- 向 UI 传值时优先用 `snapshot()`。
- 在 `derived()` 中读取时使用 `get()` 或 selector。
