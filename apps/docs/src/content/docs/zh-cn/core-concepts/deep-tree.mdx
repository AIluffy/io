## 默认深层

`oin()` 会递归处理对象与数组，深层路径可直接读写。

```ts
import { oin } from '@oin/store';

const state = oin({ user: { profile: { name: 'Ada' } } });

state.user.profile.name();
state.user.profile.name('Grace');
```

## 浅层模式

仅将第一层转为 Unit（内部使用同一 Tree 引擎，深度限制为 1）：

```ts
const state = oin({ user: { name: 'Ada' } }, { shallow: true });

state.user(); // 返回普通对象
state.user({ name: 'Grace' });
```

浅层模式下的 `commit` 不允许新增未知 key，以保持结构稳定。

## 使用 lens

```ts
import { lens, oin } from '@oin/store';

const store = oin({ settings: { theme: 'light' } });
const theme = lens<string>(store, ['settings', 'theme']);

theme('dark');
```
