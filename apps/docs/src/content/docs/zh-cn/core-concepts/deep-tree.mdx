IO 默认工作在深层模式：对象与数组会被展开成可订阅的树结构。

## 深层访问

```ts
import { io } from 'io-store';

const store = io({
  user: { profile: { name: 'Ada' } },
  items: [{ id: 1, count: 0 }],
});

store.user.profile.name.set('Grace');
store.items[0].count.update((v) => v + 1);
```

每条路径都像 Unit 一样读写，因此订阅也可以精确到叶子。

你可以把这理解为“自动原子化”：Tree 负责组织结构，路径 Unit 负责提供原子粒度的读写与订阅。

## 浅层模式（shallow）

当你只需要第一层变成 Unit，可以启用浅层模式：

```ts
const shallow = io({ name: 'Ada', age: 36 }, { shallow: true });

shallow.name.set('Lin');
```

浅层模式深度限制为 1，结构更稳定，适合“扁平 store”。

## 结构约束

- 深层模式只支持**纯对象**和**数组**。
- 传入类实例或非 plain object 会抛出 `TypeError`。
- 暂不支持把 `io()` 返回的节点直接作为值嵌入 Tree，详见 [IO 组合（设计草案）](/zh-cn/core-concepts/io-composition/)。

如果你必须存放复杂对象，建议把它包在 plain object 内，再用 `io()` 创建。
