本页解释 IO 的两个基础形态：Unit（值）与 Scope（对象作用域）。

## Unit

Unit 是最小可写状态单元，拥有清晰的读写 API。

```ts
import { io } from 'io-store';

const count = io(0);

count.get();
count.set(1);
count.update((v) => v + 1);
```

Unit 同时提供订阅与快照：

```ts
const unsub = count.subscribe((value) => {
  console.log('count changed', value);
});

const snap = count.snapshot();
unsub();
```

常用能力：

- `get()`：读取当前值
- `set(next)`：写入值
- `update(fn)`：基于旧值更新
- `subscribe(fn)`：订阅值变化
- `subscribeUpdate(fn)`：订阅 patch 更新
- `snapshot()`：冻结快照
- `reset()`：回到初始值

## Scope（对象）

当 `io()` 接收对象时，会创建 Scope。Scope 内部每个 key 都是 Unit。

```ts
const user = io({ name: 'Ada', age: 36 });

user.name.set('Grace');
user.age.update((v) => v + 1);
```

Scope 支持 `commit` 批量更新，并保持结构稳定：

```ts
user.commit((draft) => {
  draft.name = 'Lin';
  draft.age = 40;
});
```

> `commit` 适合表达“同一逻辑变更”。它会生成单次更新通知。

## Array（数组节点）

数组也是 Tree 节点的一种，支持常见的可变操作。

```ts
const todos = io([{ id: 'a', done: false }]);

todos.push({ id: 'b', done: false });
todos[0].done.set(true);
```

:::caution
请避免在数组里复用同一对象实例。每个元素保持独立更安全。
:::
