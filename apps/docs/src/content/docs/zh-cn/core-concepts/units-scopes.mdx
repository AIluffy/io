## Unit

Unit 是状态单元，提供明确的 `get/set/update` 方法。

```ts
import { io } from 'io-store';

const count = io(0);

count.get(); // 0
count.set(1); // 写入
count.update((v) => v + 1); // 更新
```

Unit 暴露以下能力：

- `subscribe(fn)` 订阅值变化
- `subscribeUpdate(fn)` 订阅更新记录
- `snapshot()` 获取冻结快照

## Scope

当 `io` 接收对象时，会生成 Scope：每个 key 都对应一个 Unit。Scope 与深层 Tree 共享同一运行时实现。

```ts
const user = io({ name: 'Ada', age: 36 });

user.name.get();
user.age.set(37);
```

Scope 支持 `commit` 进行成组更新（不允许新增未知 key 以保持结构稳定）：

```ts
user.commit((draft) => {
  draft.name = 'Grace';
  draft.age = 37;
});
```

## 数组节点

数组同样是 Unit，可以直接操作并产生更新，也与深层 Tree 共享实现。

```ts
const todos = io([{ id: 'a', title: 'Ship', done: false }]);

todos.push({ id: 'b', title: 'Document', done: false });
todos[0].done.set(true);
```
