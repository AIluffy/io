## 快速开始

<Tabs default="core">
  <TabItem label="Core" id="core">
    ```ts
    import { io } from 'io-store';

    const count = io(0);

    count.get();
    count.update((v) => v + 1);
    ```

  </TabItem>
  <TabItem label="React">
    ```tsx
    import { io } from 'io-store';
    import { useIO } from 'io-react';

    const count = io(0);

    export function Counter() {
      const value = useIO(count);
      return (
        <button onClick={() => count.update((v) => v + 1)}>{value}</button>
      );
    }
    ```

  </TabItem>
  <TabItem label="Vue">
    ```ts
    import { io } from 'io-store';
    import { useIO, ioRef } from 'io-vue';

    const count = io(0);
    const countRef = ioRef(count);

    export function useCounter() {
      const state = useIO(count);
      const inc = () => count.update((v) => v + 1);
      const reset = () => countRef.value = 0;
      return { state, countRef, inc, reset };
    }
    ```

  </TabItem>
  <TabItem label="Svelte">
    ```ts
    import { io } from 'io-store';
    import { toWritable } from 'io-svelte';

    const count = io(0);
    export const countStore = toWritable(count);
    ```

  </TabItem>
</Tabs>

## 为什么选择 IO

<CardGrid stagger>
  <Card title="原子化" icon="sourcehut">
    状态拆分为独立原子，精准订阅，零额外渲染。
  </Card>
  <Card title="路径直达" icon="seti:stylus">
    直接读写任意深度嵌套，无需改变 API。
  </Card>
  <Card title="不可变快照" icon="approve-check-circle">
    冻结快照 + 可回放变更，确保状态可预测。
  </Card>
  <Card title="行为扩展" icon="puzzle">
    组合持久化、调度、DevTools 等能力。
  </Card>
  <Card title="多框架" icon="setting">
    React、Vue、Svelte 共享同一核心契约。
  </Card>
</CardGrid>
