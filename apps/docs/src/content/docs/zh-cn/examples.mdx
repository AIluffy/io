仓库在 `examples/` 下提供了可运行示例：

## Core（Node）

```bash
cd examples/core-node
npm install
npm run start
```

## React（Vite）

```bash
cd examples/react-vite
npm install
npm run dev
```

## Vue（Vite）

```bash
cd examples/vue-vite
npm install
npm run dev
```

## Svelte（Vite）

```bash
cd examples/svelte-vite
npm install
npm run dev
```
