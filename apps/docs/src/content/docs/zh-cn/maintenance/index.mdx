## 访问权限

- 文档站为静态站点，无法在站点层面提供强读者鉴权。
- 通过仓库权限、分支保护与评审流程控制“谁可以更新文档”。
- 需要读者鉴权时，请将站点部署在访问网关之后。

## 更新流程

- `apps/docs/src/content/docs/**` 视为产品代码，必须走 PR + 评审。
- 对外 API 变更时先更新 API 参考：

```bash
nx run apps-docs:generate-api
```

- 校验生成物与源码一致：

```bash
git diff --exit-code apps/docs/src/content/docs
```

- 本地构建站点：

```bash
nx run apps-docs:build
```

## CI 约束

- CI 会生成 API 参考，防止文档与源码漂移。
- 文档部署前会执行构建，确保站点可用。
