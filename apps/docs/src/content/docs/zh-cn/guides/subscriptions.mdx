## 值订阅

```ts
import { io } from 'io-store';

const count = io(0);

const unsub = count.subscribe((value) => {
  console.log('value', value);
});

count(1);
unsub();
```

## 更新订阅

`subscribeUpdate` 提供结构化 patch 信息。

```ts
const unsubUpdate = count.subscribeUpdate((update) => {
  for (const patch of update.patches) {
    console.log(patch.op, patch.path, patch.next);
  }
});
```

## Scope/Tree 冒泡

订阅会向上冒泡，在根节点订阅即可捕获深层变化。
