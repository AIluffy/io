IO 是一个 TypeScript 状态库，由少量可组合原语与显式更新日志构成。它强调读取可预测、写入可追踪，并在各框架间保持一致的接入方式。

## 心智模型

- **Unit**：状态单元，使用 `get/set/update` 读写。
- **Scope**：由多个 Unit 组成的对象，可成组更新。
- **Tree**：深层结构，每个路径都是 Unit。
- **Update Log（更新日志）**：每次写入都会生成可订阅的 patch。

## IO 关注点

- **深层更新零样板**：`state.user.name.set('Ada')` 直接写。
- **快照安全**：读取返回冻结快照，避免误修改。
- **显式变更记录**：patch 可回放、可合并。
- **适配一致**：`snapshot() + subscribe()` 统一在各框架使用。

:::note
如果你熟悉 Zustand，可以把 IO 理解为“树形 Unit”+“更新日志一等公民”。迁移指南给出一一映射。
:::
