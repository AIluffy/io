IO 是一个面向“深层状态”的 TypeScript 状态库。你可以直接修改任何层级字段，并只订阅你实际使用的路径，从而把渲染成本压到最小。

## 适合什么场景

- 业务状态层级深、更新点多，但希望写法保持直观。
- 需要更精确的订阅粒度，减少无关组件渲染。
- 希望有可回放/可撤销的更新日志（patch）。
- 需要跨框架复用同一套状态模型。

## 核心概念

- **Unit**：最小可写单元，提供 `get/set/update`。
- **Tree**：对象/数组形成的深层状态树，每条路径都像 Unit。
- **Derived**：只读派生值，依赖变化自动更新。
- **Update Log**：每次写入生成 `patch`，可回放与撤销。

## 设计目标

- **直改深层状态**：`store.user.name.set('Ada')` 无需 reducer。
- **快照安全**：读取返回冻结快照，避免误改。
- **更新可追踪**：patch 是一等公民，调试与同步更自然。
- **统一适配契约**：`snapshot()` + `subscribe()` 覆盖主流框架。

## 最小示例

```ts
import { io, derived } from 'io-store';

const store = io({ count: 0, user: { name: 'Ada' } });
const doubled = derived(store, (s) => s.count * 2);

store.count.update((v) => v + 1);
console.log(doubled.get());
```
